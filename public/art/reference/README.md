# Reference garden art — 2026-09-23

Production assets for the two user-provided landscape/portrait designs. Generated with the built-in `image_gen` reference-image workflow; no external image API or runtime service is required. The source images were inspected and supplied using `referenced_image_paths` (reference/edit workflow, equivalent intent to `images/edits`, not a direct HTTP endpoint call).

## Files

- `ui-atlas.webp`: lossless RGBA master, 1536 × 1024. Twelve isolated UI assets. Its RGB channels retain the generation's background colors under zero alpha; consumers must preserve alpha.
- `refresh.png`, `hammer.png`, `rocket.png`, `bomb.png`: four generated button cutouts; live counts are DOM overlays.
- `sound.png`, `help.png`, `settings.png`: toolbar button cutouts. Sound is wired to the same saved preference as Settings.
- `score-panel.png`, `crown.png`: empty two-row score plaque and decorative crown. Labels/scores remain live DOM.
- `tray.png`: empty three-compartment tray; each piece is rendered in its own live WebGL canvas.
- `button.png`, `star.png`: spare cutouts retained with the complete atlas.
- `pedestal.webp`: transparent flower/ivy/stone platform, cropped and resized to 1252 × 516.
- `valley-landscape.webp`: 1660 × 948 landscape, WebP quality 91.
- `valley-portrait.webp`: 941 × 1672 portrait, WebP quality 91. Separate composition preserves the cottage/corgi/castle on phones.
- `prompts.json`: complete generation prompt set. A follow-up UI edit requested removal of the brown/green backdrop while preserving all twelve objects and their positions, with actual alpha transparency.
- `slices.json`: source coordinates and output dimensions for every PNG; regenerate using `python tools/slice-reference-art.py <RGBA-master.png>`.

Slicing, cropping, resizing and WebP encoding use Pillow; the artwork itself was generated by the image tool. No gameplay cube or candidate block is baked into the scene images. Source dimensions were inspected rather than assumed from the requested sizes.
