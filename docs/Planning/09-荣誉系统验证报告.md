# 荣誉系统可达性与频率验证报告

> 版本：v1.2（2026-09-12）
> 验证器：`E:\WorkSpace\DSH\Temp\reach.mjs`（可复跑，`node reach.mjs p1|p2|all`）
> 模型：严格镜像 `src/game/board.js` —— 5×5×5 立方体**外壳**，格子按晶格坐标存储，每面 5 行 + 5 列
> 目的：用程序判定 `08-荣誉与排行榜系统.md` 里的荣誉「哪些真能触发、多常触发」，取代手工推导

## 0. 方法

| 阶段 | 方法 | 性质 |
| --- | --- | --- |
| **Phase 1** | 对每个（拼块 × 朝向 × 落点）DFS 穷举所有可行缺口组合 | **完备搜索**（`timeUp: false`、零截断）——未找到即**可证明不可达** |
| **Phase 2** | 完整对局模拟，三种玩家策略各 2000 局 | 统计频率，受策略影响，非完备 |

模型规模：外壳 **98 格**、**60 条线**、**2322 个合法摆放**、28 个去重朝向。

## 1. Phase 1：可达性判定（完备）

### 1.1 一次落子的消除上限 = **12 条线**

`maxLinesInOneMove = 12`。**8 号文档写的「单面上限 5」正确，但「跨面上限 10」是错的。**

错误原因：原文按「每个格子最多属于 2 条线」计数——那是**单面**的算法。晶格格子在**它所属的每一个面**上都各算一对行列，角格属于 3 个面 → 最多 6 条线关联。

| 拼块 | 最大线数 | 拼块 | 最大线数 |
| --- | ---: | --- | ---: |
| Line4 / L / J | **12** | Line3 / Square / S / Z / Corner | 10 |
| T | 11 | Line2 | 8 |
| | | **Dot（单点）** | **6** |

> **单点块是全场最高效的引爆器**：放在角上，三条棱各同时算作两个面的一行一列 = 6 线。8 号文档把它当"1 格小垃圾块"，判断完全反了。

### 1.2 荣誉可达性

| 荣誉 | 可达 | 搜索树命中次数 |
| --- | :---: | ---: |
| FACE_WIPE 净面 | ✅ | 36,961 |
| DUAL_FACE 双面 | ✅ | 32,104 |
| CROSS 十字 | ✅ | 26,435 |
| PURE_CUBE 净体（98格全清） | ✅ | 21,305 |
| TRIPLE_FACE 三面 | ✅ | 15,076 |
| DOUBLE_CROSS 双十字 | ✅ | 3,428 |
| PERFECT_STRIKE 满贯（单面5线） | ✅ | 1,064 |
| **CUBE_BURST（≥4面）** | ❌ **不可达** | 0 |

- `CUBE_BURST` 不可达的原因已在 08 文档 §2.2 修正：4 格连通块最多触及 1 个角，一个角属于 3 个面 → **面数上限为 3**。删除正确。
- 但**可达 ≠ 可获得**：Phase 2 显示 `PERFECT_STRIKE` 在 6000 局里一次都没出现。

| **2 \| 2** | 209,515 | **29.6%** | ← **跨面连爆是常态，不是彩蛋** |
| 2 \| 1 | 30,426 | 4.3% | |
| 3 \| 2 | 19,873 | 2.8% | |
| 4 \| 3 | 2,048 | 0.29% | |
| 3 \| 3 | 1,837 | 0.26% | |
| 4 \| 2 | 1,085 | 0.15% | 比 4\|3 更稀有 |
| 3 \| 1 | 901 | 0.13% | 单面三线极难 |

## 3. 最严重的发现：**游戏几乎不会结束**

`noise` 策略下 **99.1% 的对局撞上 600 步上限仍未 Game Over**。

量级对比：

| | 棋盘格数 | 最大拼块 | 线数 |
| --- | ---: | ---: | ---: |
| Block Blast | 64（8×8 单面） | 9 格 | 16 条 |
| **VoxalBlast** | **98（外壳）** | **4 格** | **60 条（且棱/角共享）** |

单个拼块占棋盘比例从 ~14% 掉到 ~4%，消除机会翻近 4 倍。**空间压力小了一个量级**，高手可以无限玩。

后果：
- PRD「单局 2~5 分钟」保不住
- 排行榜分数无上限 → 变成「比谁有耐心」
- §4.6 的阶位表（60,000+ 满贯者）与真实中位分 209,800 差 3.5 倍，作废

> ⚠️ 局限：模拟器是**完美操作者**（瞬时评估 6 面 × 4 朝向 × 全部位置），真人受 3D 旋转观察成本限制，不会这么强。因此**真人测试仍是必要的**，但「99.1% 撞上限」的信号强度已足以要求预留收紧手段。

## 4. 结论与建议

### 4.1 荣誉体系必须重构：从「按类型」改为「按规模」

现状是给「双面」「十字」这类**高频事件**发徽章 → 播报刷屏。应改为给**规模里程碑**发徽章，门槛直接用上面的真实频率标定：

| 建议荣誉 | 触发 | 真实占比 | 定位 |
| --- | --- | ---: | --- |
| — | 2线2面 | 29.6% | **只给倍率，不发荣誉** |
| 小成 | ≥3 线 | 3.2% | 小字播报 |
| 名场面 | ≥4 线 或 3 面同爆 | 0.47% / 0.58% | 横幅 |
| 史诗 | ≥5 线 或 (≥4线 且 3面) | 0.027% / 0.29% | 大横幅 |
| 传说 | ≥6 线 | 0.003% | 全屏名号 |

保留真正稀缺的三枚：`PURE_CUBE`（3.6% 局）、`DOUBLE_CROSS`（0.1% 局）、`PERFECT_STRIKE`（需重新标定门槛，当前等于不存在）。

### 4.2 倍率表按 1~12 线重做

原表在 5 线封顶，实际可达 12 线，且真实分布已给出每档概率，可直接标定凸曲线。

### 4.3 难度是一个**必须先于荣誉**解决的问题

候选旋钮（建议组合 1+2）：

1. **削供给**：每回合 3 块 → 2 块（直接砍 33% 输入量）
2. **加重块池**：恢复 5 格直线，或提高 4 格块权重
3. 加压力机制（每 N 步不消线则注入障碍格）
4. 缩棋盘（5×5 面 → 更小，会牵动全部已有规则，代价最大）

## 5. 复跑与留档

验证器已从临时目录移入项目，可随时复跑：

```bash
node tools/reachability.mjs all                                # Phase 1 + Phase 2
node tools/reachability.mjs p1                                 # 仅完备穷举（约 0.2s）
node tools/reachability.mjs p2 --strategy=noise --games=2000   # 仅对局模拟（约 20s）
node tools/reachability.mjs all --out=tools/reachability-baseline.json
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--strategy=` | `noise` | `greedy` 上界玩家 / `noise` 75% 最优（近似真人）/ `random` 下界玩家 |
| `--games=` | 2000 | 模拟局数 |
| `--stepCap=` | 600 | 单局步数上限，超出即计入 `gamesReachedStepCap` |
| `--out=` | — | 将 JSON 结果写入文件 |

**基准数据**：`tools/reachability-baseline.json`（2026-09-11，noise × 2000 局）。

**何时该重跑**：任何改动棋盘尺寸、拼块池、消除规则或落子朝向规则之后。验证器直接镜像 `board.js` 的晶格模型，改完代码重跑即得新基准。

> ⚠️ **判读红线**：若 `phase1.timeUp == true` 或 `truncatedPlacements > 0`，说明搜索被截断，**该次结果不能用来证明任何事件不可达**，只能证明「已找到的那些可达」。只有零截断的 Phase 1 才具备完备性。

> ⚠️ **模型边界**：验证器不含道具、不含真实拼块供给权重（按 11 类均匀随机）、不含 UI 操作成本。对局时长与频率的**绝对值**会与真机有偏差，但可达性结论与量级关系可靠。

### 6.3 旧荣誉口径（复现 `09` §2.2 的对照表）

同一批对局下旧口径为：`DUAL_FACE 109.4/局`、`CROSS 14.0/局`、`FACE_WIPE 7.1/局`、`TRIPLE_FACE 1.7/局`、`DOUBLE_CROSS 0.029/局`、`PURE_CUBE 0.033/局`、`PERFECT_STRIKE 0`、`CUBE_BURST 0`。与 §2.2 的差异全部来自拼块池去掉 Line 4，**结论不变**：按"类型"发荣誉依然会刷屏。

### 6.4 本次新增的可观测量

- **`scorePercentiles`**（模型内分位：p25 164,020 / p50 169,805 / p75 175,520 / p90 181,660 / p99 192,135）——注意它们挤在一起，因为是"600 步打满"的对局分布；**不能拿它当阶位分档依据**（`08` §4.6 要的是真实玩家分位）。
- **`avgBestChain` 8.53 / `maxChainObserved` 14**：链机制上线后，`08` §11 里"平均链长待测"一项在模型内有了参考值（真人会显著更低）。
- **`honorShareOfClears`**：见 §6.2，门槛标定的正确口径。

### 6.5 结论

1. **规则改动本身通过**：Phase 1 零截断（12 线上限不变，`CUBE_BURST` 仍不可达），Phase 2 六面连爆成为常态。
2. **难度阻塞项加重**：六面全检让空间压力进一步下降，`noise` 策略下 100% 的对局打满 600 步。难度旋钮（削供给 / 加重块池）必须优先于任何"按局标定"的门槛。
3. **阶位表继续留空**：模型分位不能替代真实玩家分位。
