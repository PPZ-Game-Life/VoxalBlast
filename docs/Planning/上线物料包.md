# VoxalBlast 上线物料包（CrazyGames Basic Launch）

> 版本：v0.8.3 · 2026-09-17。平台硬规格取自 CrazyGames 官方文档（[Requirements Intro](https://docs.crazygames.com/requirements/intro/)、[Game covers](https://docs.crazygames.com/requirements/game-covers/)），本页数字与官方页面逐条对齐；平台改规则时先核官方页再改本页。
> 本页只管"提交时填什么、传什么图/视频"，玩法与美术口径见 [05](05-美术方向与视觉规范.md)；旧的制作说明 [06](06-平台宣传素材与视频规范.md) 仍有效，但凡与本页冲突，以本页（官方现行规格）为准。

## 0. 这一包东西解决什么

物料只解决一件事：**CTR（点不点）**。它不解决留存。

上次 Basic Launch 的数据摆着：Gameplay Conversion 45.68%（点进来的人确实在玩）、平均时长 2m28s、D1 1.59%、曝光 Bottom 20%。也就是说，进来的门不算窄，是**第二天没人回来**。所以物料必须做，但别指望它救留存——封面视频是往桶里加水，桶底那几道缝（首分钟闭环、回来的理由）不补，加多大都是加。

物料清单只有 6 件：**1 个名字 + 1 段描述 + 1 段操作说明 + 3 张封面 + 2 支预览视频 + 1 张自检表**。

## 1. 命名决策

### 1.1 现名 VoxalBlast 的问题（不是"不好听"，是三个功能缺失）

1. **读不出、拼不对**：`Voxal` 是自造词，母语者不确定读 /ˈvɒksəl/ 还是 /ˈvoʊksəl/，听到也拼不出来。名字的第一功能是"被复述"，这条直接失败。
2. **语义错位**：`Voxal` 指向 voxel（体素建造），而我们是"立方体六个面上的贴块消除"。看图才懂，看名字会误判成我的世界类沙盒——预期错位会拉低点击后的转化。
3. **吃不到品类搜索**：站内搜索与推荐吃的就是 `block` / `cube` / `puzzle` / `3D` 这类品类词。现名里一个都没有，等于把自然流量入口全关了。`Blast` 虽然是品类词，但落在 `Block Blast` 这个平台巨头后面，单独靠它没有独占性。

### 1.2 判定标准（改名前拿来对，不许凭感觉）

| 维度 | 通过线 |
| --- | --- |
| 一秒复述 | 看封面 1 秒后能念对、拼对 |
| 玩法暗示 | 名字里能听出"方块 / 立体 / 消除"三者之一 |
| 搜索独占 | CrazyGames 站内 + Google Play + App Store 同名同类检索，撞名同类游戏 ≤ 2 个 |
| 可延展 | 能挂副标题做系列（XX: Six Sides / XX 2） |
| 字数 | ≤ 12 个英文字符，短过 `VoxalBlast`(10) 更好——一秒扫不过是上限 |

### 1.3 三个候选

| 候选 | 逻辑 | 代价 |
| --- | --- | --- |
| **Cubeblast**（主推） | `Cube` + `Blast` 全是高流量品类词，站内搜索直接吃 `cube blast` / `block blast` 邻域；改动成本最低（只把 `Voxal` 换成 `Cube`） | 撞名多，商标需查；玩家会先用"又一个 Block Blast 换皮"的低预期看你，封面必须把"六面"差异打出来 |
| **Blockface**（差异化） | `Block`(品类词) + `Face`(面) 双关，母语者原生词、好记好拼，直接说"往面上贴方块"；图标极好做——一个立方体正面 | 站内搜索吃 `block` 但吃不到 `blast`；`blockface` 在英语建筑/网络语境另有含义，商标检索必做 |
| **Cube Blast: Six Sides**（副标题式） | 主标题吃搜索，副标题一眼说清差异，兼容前两个方案 | 名字变长，封面上排版压力大，只在横版封面站得住 |
| **CubeBlaster** | 与 `Cubeblast` 同源，多一个 `-er` 更像品牌 | `-er` 把动作变成人/物，平台品类词是 `blast` 不是 `blaster`，等于花一个词的价钱买半个人的搜索；听写/拼写在 `Cube Blaster` / `Cube Blast` / `Cubeblast` 三种写法间摇摆；**站外已实存同名**（见 §1.5）。不建议 |

**结论**：把 `Voxal` 换掉，`Blast` 留着——留的是品类搜索入口，换的是读不出来的那半截。要独占选 `Blockface`（§1.5 唯一三处全零的候选），要吃品类词选 `Cube Blast`（去掉 `-er`），不要折中方案。**决策只能在上线前做**：上线后再改，等于把已经积累的站内搜索与用户熟悉度清零重来。

### 1.5 撞名检索结果（2026-09-17，`node tools/name-collision-check.mjs` 可复现）

探针用 `1v1-lol` / `moto-x3m` / `block-blast` 三个已知在架游戏校准（均 200），`voxalblast` 自身 404 与"Basic Launch 未启用"一致。完整记录 `artifacts/naming-collision-2026-09-17.txt`。

| 候选 | CrazyGames 站内 | App Store（iTunes API） | Steam | 站外同受众 Web 门户（人工查） |
| --- | --- | --- | --- | --- |
| `Cube Blaster` | 干净（`cube-blaster` / `cubeblaster` / `cube-blaster-3d` 全 404） | 20 hits、同名 0（`Cube Blaster 3D` 的旧链接仍在搜索结果里，API 已检索不到，疑似下架/分区） | 0 | **Y8 有正在运营的同名 [Cube Blaster](https://www.y8.com/games/cube_blaster)**（桌面浏览器免费玩）；Playgama / igroutka / Fupa 上有 `Cube Blaster 2048`；Google Play 有同名包 `com.everfun.cube.blaster` |
| `Cube Blast` | 干净 | 20 hits 全是 `Cube Blast 3D - Voxel Pop` / `Cube Blast Jungle` / `Cube Blast Match 3` 等近似，同名 0 | 1 hit、同名 0 | 词域红海（大量 `Cube Blast*` 换皮），Google Play 需人工过 |
| `Cubeblast` | 干净 | 同名 1（日文 `暇つぶしゲーム Cube Blast`） | 1 hit、同名 0 | 未见 |
| `Blockface` | 干净 | 18 hits、近似 0 | 0 | 未见（英语建筑/网络语境另有含义，商标必查） |
| `Sixface` | 干净 | 12 hits、近似 0 | 1 hit、同名 0 | 未见 |

**判定口径**：CrazyGames 站内干净 = 平台内搜索拿得到名字的全部曝光，目前查下来所有候选都没问题；站外撞名影响的是"用户到站外回头搜"。所以 `CubeBlaster` 不是不能用，而是它买到的只是品类词邻域、不是独占，还额外背上拼写歧义——同一笔钱，`Cube Blast` 少一个歧义，`Blockface` 多一份独占。

**探针的边界（别当成结论）**：`/game/<slug>` 只覆盖精确 slug，站内**同名不同 slug** 会漏；Google Play / Y8 / Poki / Playgama 无公开检索 API，只能人工查；商标库（USPTO TESS / EUIPO）与域名未查。提审前这四项人工过一遍再签字。

### 1.4 中文名（现在不是杠杆）

平台流量以英文用户为主，中文名不影响曝光，**这轮不必纠结**。等真要上微信小游戏/抖音小游戏时再单独起，方向是「六面方块」「方块六面消」这类直给品类词——理由同上，中文渠道更吃搜索关键词。

Mouse / touch: drag a piece from the tray onto any face to place it. Drag the

Keyboard: W/S flip the cube around the screen's horizontal axis, A/D around the

## 3. 封面（3 张，官方硬规格）

| 用途 | 比例 | 尺寸 |
| --- | --- | --- |
| 横版 | 16:9 | 1920×1080 |
| 竖版 | 2:3 | 800×1200 |
| 方版 | 1:1 | 800×800 |

三张必须是**同一套视觉**（同角度、同配色、同字体），让用户在方版里也认得出。

**官方禁止项**（违反直接打回）：边框；除游戏名以外的任何文字（`New` / `Updated` / `Play Now` 全都不行）；商店或应用图标；无授权素材；模糊或像素化图像。

**构图口径**：

- 主视觉是立方体的 3/4 视角，**至少看到两个面**，否则"立体六面"这个差异点在图里就丢了。
- 画面上要有一个**张力瞬间**：某一行只剩一格就满，候选块正悬在那一格上方。静态图也要读出"要爆了"。
- 名字压在安全区（横版偏左或上方），用风格化字体，别压住关键格子。
- 底色沿用游戏内的木质田园景，与实机一致；不要另起一套画风。
- 竖版独立构图，不是横版裁切。

## 4. 预览视频（2 支，官方硬规格）

- 时长 **15–20 秒**，超了平台会裁到 20 秒
- 体积 **≤ 50MB**，无声音
- **必须两支**：1080p 横版 16:9 + 1080p 竖版 2:3
- **首帧用静态封面**（缩略图→动图无缝衔接）
- 禁止：黑屏/logo 转场、上下黑边、系统默认鼠标光标、`Play Now` 等促销文字、App/社交图标
- 不要自己做快进——平台处理时会自动轻微加速

### 4.1 16 秒分镜

| 时间 | 画面 | 目的 |
| --- | --- | --- |
| 0–1s | 首帧 = 横版封面静置 | 与缩略图无缝 |
| 1–3s | 立方体轻转展示六面 | 一秒建立"这是立体的" |
| 3–6s | 拖一块落面 → 凑成整行 → 消除爆发 | **前 3 秒内必须出现一次消除**，这是 hook 底线 |
| 6–10s | 三连快剪：放置→消除→分数跳 | 证明"有节奏、能连" |
| 10–13s | 翻面救另一面 + 一次**跨面连爆** | 差异点，至少出现 1 次，不能省 |
| 13–15s | 棋盘接近满 → 火箭/炸弹救场 → 清屏 | 高潮 |
| 15–16s | 结算界面（分数/最高分/再来一局） | 落点在"我还想再来一局"，不要 logo 转场 |

录制必须来自 `npm run build` + `npm run preview` 的正式构建（无开发版版本号），裁切/字幕/配乐（无声）可后期，**不许编造奖励或玩法**。
