# VoxalBlast 产品概览（现行 PRD）

> 实现基线：**v0.8.16**，按当前源码静态核对；不是新增设计或本轮实机验收。历史立项范围见 [原稿](../Archive/Planning/01-立项PRD.md)。

## 产品与核心循环

单人、无重力的六面贴块消除游戏。玩家转动六面体，在当前朝向自己的 5×5 面放置固定朝向的平面拼块；填满行或列后消除，棱角共享可让一次落子在多个面同时成线。棋盘是 5×5×5 **外壳的 98 个唯一格**，不是 125 格内部填充空间。

进入主页 → 新游戏或继续 → 观察并翻面 → 拖放候选 → 六面同批结算 → 三块用完补一批。

若剩余未用候选在六面及四种面内方向上均无合法落点：

1. 换批还有次数：提示换批，保留局面；
2. 无换批但锤子、火箭或炸弹有次数：提示清理挡路格，保留局面；
3. 四项道具均耗尽：结算。

救局豁免只检查次数，不扫描清理目标能否实际救活，也不会自动替玩家使用道具。

## 当前边界与目标

- 没有联机、账号系统、自建在线排行榜、商店、金币、付费、每日挑战或局内道具补给系统。
- 平台全球榜、广告请求及完整广告生命周期未完成实平台验证；阶位阈值全为 `null`，六面制霸徽章未实现。
- “短局 2～5 分钟”“新玩家 30 秒内会玩”是**设计目标**，不是已达成数据。
- 十五类池（v0.9.0）尚无真人数据；十四类池有历史机器人测量，但步数不能换算成真人时长或留存。`random`、`noise`、`greedy`、`space` 是不同策略，不能混称“真人典型打法”。见 [现行池难度报告](../Technical/DIFFICULTY_CURVE_POOL14.md)（十四类冻结臂）与 [发牌 P1 实现记录](../Technical/DEALING_P1.md)。
- **发牌器的难度目标（容错区间）是首轮试验值**，且实测在稀疏盘面上不可达；30/60/90 的"明显难度节点"目前只有机制保证，没有真人验证。
- 本地存档不是云存档；物理手机、低性能表现、远端部署和实平台能力须另行验证。

## 表现与交互原则

让玩家看清当前面、候选轮廓、共享棱角与落点。三维特点靠六面翻转和跨面消除表达，不暗示往内部填充。候选朝向固定，旋转的是棋盘；主页展示同源棋盘与开局入口。
