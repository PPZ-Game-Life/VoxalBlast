# VoxalBlast 产品概览（现行 PRD）

> 基线：v0.7.0 / 2026-09-14；按当前实现整理。历史立项范围见 [原稿](../Archive/Planning/01-立项PRD.md)。（v0.7.0：美术方向改为木质田园，规则与数值未变）

## 产品与核心循环

单人无重力立体拼块消除游戏。玩家转动一颗六面体，在当前朝向自己的 5×5 面上放置固定朝向的平面拼块；填满行或列后消除，棱角共享可让一次落子在多个面同时成线。

进入主页 → 新游戏或继续 → 观察并翻面 → 拖放候选 → 六面同批结算 → 消耗完三块后补一批 → 无位置时尝试换批 → 无位置且无换批次数时结算。

## 已实现范围

- 六面共享晶格、开局预置、三块供给、六面全检、连击与多层计分。
- 鼠标/触摸拖拽、吸附与取消；世界轴翻面、键盘旋转、滚轮缩放。
- 局内换批 ×2、锤子 ×1、火箭 ×1、炸弹 ×1。
- 主页、中文设置、操作说明、Game Over、断点续玩。
- 本地最高分、周最佳、个人纪录、荣誉墙、最近十局。
- 程序化 3D、实体玩具拼板、同源主页缩影、厚底 UI、原创矢量图标、粒子与声音/触感调用。
- CrazyGames 可选适配层及未接通时的降级入口。

## 当前边界

没有联机、账号系统、自建在线排行榜、商店、金币或付费系统。平台全球榜接入与广告生命周期未完成实平台验证；不能把适配接口视为已经上线。阶位阈值仍为空，六面制霸徽章未实现。

“短局 2～5 分钟”和“新玩家 30 秒内会玩”保留为设计目标，未证明达到。历史模拟暴露单局过长问题，详见 [待办](../Technical/KNOWN_GAPS.md)。

## 表现与交互原则

让玩家看清当前面、候选轮廓、共享棱角与落点。三维特点靠六面翻转和跨面消除表达；不暗示往内部填充。固定候选朝向，旋转的是棋盘。主页直接展示同源棋盘和开局入口，不承担营销长文。

运行时美术全部由代码生成，不依赖外部图片、贴图、视频或预制模型。规则见 [02](02-核心规则与数值.md)，交互见 [03](03-交互与表现需求.md)，视觉见 [05](05-美术方向与视觉规范.md)。
