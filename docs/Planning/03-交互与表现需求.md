# VoxalBlast 交互与界面

> v0.5.0 实现基线；依据 main.js、swipe.js、keyboard.js、styles.css、toy.css。

## 1. 页面与布局

启动进入主页，提供新游戏/继续游戏、最高分、排行榜、设置。主页是覆盖层，背后的游戏画布保留尺寸；静态棋盘缩影复用当前场景几何。首次启动缩影来自初始化盘面，不承诺是续玩存档的截图。

- 常规桌面：顶部分数、BEST、连击和操作入口；中央棋盘；底部候选与道具。
- 顶部不显示游戏名（占位样式仍留在 styles.css）。版本号仅开发构建显示；设置已中文化，局内状态提示、部分统计与荣誉标题仍含英文，并非全量中文化。

styles.css / toy.css 中实际生效的断点：

| 条件 | 效果 |
| --- | --- |
| ≥641px | 顶部显示 ⌨ 操作说明入口；更窄只隐藏入口，键位仍生效，卡片仍可从设置进入 |
| >900px | 桌面列序：棋盘 → 候选 → 道具 |
| ≤900px | 改单列，顺序为 道具 → 棋盘 → 候选；主布局底部让出安全区，候选成为最下缘 |
| ≤700px | 候选与道具尺寸收紧；键盘轴提示胶囊整体隐藏 |
| ≤460px | 顶部胶囊、主页间距与说明卡片进一步收紧 |
| 高度 ≤600px | 主页与候选改用矮版尺寸，不改变列序 |
| 高度 ≤430px 且宽度 ≥600px | 左侧棋盘，右侧候选与道具；主页双列 |

## 2. 翻面与缩放

从棋盘区域开始拖动用于旋转，从候选开始拖动用于放置，两者互斥。一次手势只认一个固定世界轴：横向绕 Y；起点在棋盘水平范围内的纵向绕 X；左右侧带纵向绕 Z。

超过约 30° 阈值转向下一面，否则弹回。每次最多 90°，用四元数维持网格姿态，不因之前转向改变手势轴。X/Y 停稳可保留各 ≤8° 展示偏摆；Z 归正清除偏摆。滑动标尺按棋盘投影大小计算，起手需满足方向优势与距离门槛。

W/S 对应俯仰，A/D 对应偏航，Q/E 对应平面自转；按住不连续触发。按键时棋盘附近浮出「键帽 + 轴环 + X/Y/Z」小胶囊，约 0.7 秒自动淡出，不接收指针事件，≤700px 隐藏。说明卡片打开时按键只驱动该行迷你方块并让键帽下沉，棋盘姿态不变。滚轮缩放相机，无镜头复位入口。候选始终保持固定的屏幕形状朝向；槽内使用固定斜视 3D 预览，并非纯正视平面图。

## 3. 拖放与取消

越过拖拽阈值后显示手上拼块；进入立方体轮廓附近且有合法位置时隐藏手上幽灵，显示面上预览。不能同时显示两个正在拖动的拼块。轮廓内无合法位置时幽灵转红。

鼠标抬升固定 10px；触摸抬升为 12px + 拼块屏幕高度的一半，上限 120px。吸附后按相对位移步进，每约半格触发一次取整；目标非法时停在前一合法位置，退回后继续跟随。

候选条和道具条共同构成取消区。拖回后松开取消；Esc、右键和输入中断也结束拖拽。取消不消耗拼块、不计分。打开主页/设置、失焦、页面隐藏等路径清理拖拽与旋转手势。

## 4. 暂停、续玩与结算

主页、设置/操作说明、页面不可见和局终等状态共同控制暂停。页面隐藏/失焦会结束当前手势；不要把“失焦清理手势”等同于所有环境都已有完整广告暂停流程。

运行状态变化后保存棋盘、候选已用状态、道具、荣誉/连击及姿态。回到主页保留未完局；继续读取存档。Game Over 写入本地纪录并删除续玩存档。重新开始直接开新局。

声音和触感可单独开关；触感是否实际发生取决于浏览器/设备。操作说明中可用键盘驱动示意小立方体。

## 5. 反馈与验证

分数跳字、连击条、荣誉横幅、声音、震动、线光束、星星和粒子由现有事件触发。×2 起点亮连击；反馈分档见 [08](08-荣誉与排行榜系统.md)。实体壳要求消除和道具效果沿面法线外移，参数见 [05](05-美术方向与视觉规范.md)。
