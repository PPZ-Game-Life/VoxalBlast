# VoxalBlast 交互与界面

> **当前实现基线：v0.8.21，静态代码核对于 2026-09-22。** 依据 `src/main.js`、`src/rendering/swipe.js`、`keyboard.js`、`config.js`、`index.html` 与样式表整理。
> 本文只把代码中已存在的路径写为“已实现”；视觉手感、触屏兼容、平台容器行为等未在本轮运行验证的内容统一列入末尾待验证项。

## 1. 当前已实现：页面、布局与状态

启动时主页覆盖游戏画布，提供新游戏/继续游戏、最高分、排行榜和设置。是否显示“继续游戏”由 `sessionStore.read()` 是否返回可玩快照决定；主页缩影由当前场景几何克隆生成，不是续玩存档截图（`refreshHome()`、`renderHomeBoard()`）。

局内 HUD 包含 SCORE、BEST、连击、操作说明和设置；中央为 3D 棋盘，候选区固定三槽，道具区四槽。版本徽标 `#app-version` **在任何构建下都显示**（`src/main.js` 只写文本，不再按 `import.meta.env.DEV` 隐藏）：它在旧版曾是 dev-only，手机上的正式产物因此看不到自己跑的是哪一版；窄屏只缩字号（≤460px `font-size: .5rem`），不设 `display:none`。主页覆盖时它随 `.topbar` 一起 `visibility: hidden`。

样式表当前布局断点：

| 条件 | 当前布局 |
| --- | --- |
| ≥641px | 显示顶部“操作说明”入口；窄屏只隐藏入口，键位监听仍存在 |
| >900px | 桌面顺序：棋盘 → 候选 → 道具 |
| ≤900px | 单列顺序：道具 → 棋盘 → 候选 |
| ≤700px | 候选与道具收紧，局内键盘轴提示隐藏 |
| ≤460px | 顶部、主页和说明卡片进一步收紧 |
| 高度 ≤600px | 主页与候选使用矮版尺寸 |
| 高度 ≤430px 且宽度 ≥600px | 短横屏：左棋盘、右候选与道具；主页双列 |

## 2. 当前已实现：翻面、方位与缩放

### 2.1 指针手势

从候选槽 `pointerdown` 开始的是拼块拖放；从画布开始的是视角手势，两者互斥（`beginDrag()`、`beginViewDrag()`）。

一次画布手势只锁定一个世界轴：

- 横向拖动：绕世界 Y 轴偏航；
- 在棋盘水平投影范围内纵向拖动：绕世界 X 轴俯仰；
- 从棋盘左右侧带开始纵向拖动：绕世界 Z 轴平面自转。

轴锁定不是首个像素立即决定：领先方向至少达到 `axisLockPx=16`，通常还需达到 1.2 倍方向优势；到 `axisHardLockPx=44` 仍接近对角时由较大方向接管（`gestureAxisReady()`、`pickGestureAxis()`）。右侧带下滑为顺时针，左侧带下滑为逆时针（`bandRollSign()`）。

逻辑姿态 `cubeBase` 只累计 90° 世界轴步进；偏航/俯仰方位 `bearingYaw`、`bearingPitch` 是玩家保留的微调层。释放规则由 `planAxisRelease()` 决定：

- 偏航/俯仰总偏移未越过 `stepThreshold=0.52rad`（约 30°）时保留微调；
- 超过阈值时只翻一个面，恢复翻面前方位；
- Z 轴不保留残余方位，只会翻 90°或回到网格姿态；
- 微调实际钳制范围为：偏航 **−14°～+5°**，俯仰 **−2°～+8°**（`ROTATE_STYLE.bearingBand`）；
- 非微调释放使用 `easeOutCubic`、0.22 秒球面插值，无过冲。

相机当前为弱透视参数：桌面 FOV 6°、移动端 7°，方向 `[0.273, 0.139, 0.952]`。滚轮按 0.92/1.08 倍缩放并钳制在 `cameraZoom=0.7..1.7`；当前没有独立镜头复位按钮。

### 2.2 键盘

`W/S` 绕 X，`A/D` 绕 Y，`Q/E` 绕 Z；映射来自 `axisForKey()`。按住不连发（`event.repeat` 被吞掉），一次按键触发一次四分之一转。

操作说明卡打开时，六个键只驱动说明行里的迷你方块，真实棋盘保持暂停。正常局内按键成功后会短暂显示“键帽 + 轴 + X/Y/Z”提示。

**边界：道具瞄准态下 `handleRotateKey()` 会因 `itemActive` 返回，故 W/S/A/D/Q/E 当前不能转面；此时只能在画布上拖动转面。** R/C 仍可在火箭瞄准态切换 Row/Col。旧文档中“瞄准态键盘也可转面”不是当前实现。

## 3. 当前已实现：候选拖放与取消

候选槽按下后，移动不足 6px 仍按点击选择处理；越过阈值才进入实际拖拽。拖动时：

- 画布外/棋盘外显示随指针移动的手持拼块；鼠标固定抬升 10px，触摸抬升为 12px + 拼块屏幕高度一半，上限 120px；
- 进入棋盘轮廓附近且存在合法位置时，手持拼块隐藏，改显示棋盘落点预览；
- 棋盘范围内没有合法位置时，手持拼块保留并使用非法色；
- 合法预览使用候选拼块自身颜色，非法态使用 `RENDER_PALETTE.invalid`；
- 候选条与道具条共同构成取消区，拖回后释放不消耗拼块、不计分；
- `Esc`、右键、`pointercancel` 和打开设置可取消候选拖拽。

落点使用当前画面朝向推导出的拼块格形；结算使用预览阶段已经确定的 `currentDrag.cells`，避免释放时重新计算造成所见与落点不一致（`finishDrag()`）。

## 4. 当前已实现：暂停、续玩与局终

`syncPause()` 的暂停来源为主页、页面隐藏、局终、设置、操作说明，以及**开场创建波次进行中**（见 §6）。打开主页/设置会清理候选拖拽和道具瞄准；页面隐藏还会清理候选拖拽、道具瞄准、道具撤销窗口及旋转手势，保存未完局，并让进行中的开场波次直接结算到位。

窗口 `blur` 当前只调用 `cancelViewDrag()`，不等同于完整的候选拖拽/道具状态清理；不要把它写成所有输入都已覆盖的失焦暂停流程。

未完局快照键为 `voxalblast.session.v1`，保存：

- 棋盘晶格、分数、总消除线；
- 三个候选及已用状态；
- 四种道具次数；
- 连击、局内最佳、荣誉及点亮面等运行统计；
- 逻辑姿态与玩家方位。

快照在落子、道具成功、换批、撤销、回主页、页面隐藏等状态变化后写入。`localStorage` 不可用时退化为当前页面会话内存续玩；刷新/关闭后的持久化不作保证。Game Over 先写已结束局纪录，再清除续玩槽；重新开始会创建新局、重置道具、荣誉运行态及方位。

## 5. 当前已实现：反馈

落子结算顺序为：全六面满线判定 → 连击 → 荣誉 → 分数 → 反馈（`settlePlacement()`）。

- 无消除 L0；单线 L1；双线 L2；三线 L3；四线或三面 L4；五线以上，或四线且三面，为 L5；
- L5 的 0.6 倍/400ms 只影响动画时钟，输入逻辑不读取慢放状态；
- 分数跳字、连击提示、荣誉横幅/徽章、音效、触感、线光束、星星和粒子由现有事件调用；
- 声音和触感可分别关闭，但触感是否发生仍取决于浏览器/设备能力；
- 画布由 `ResizeObserver` 跟踪容器尺寸并重算投影与缓冲区。

荣誉、分数和排行榜边界见 [08](08-荣誉与排行榜系统.md)，道具瞄准与死亡前救场见 [07](07-道具系统设计.md)。

## 6. 当前已实现：进入单局的开场创建波次（v0.8.21）

进入一局时六面体不是瞬间完整出现，而是被**一道波次扫出来**：波前按屏幕空间“左下 → 右上”的斜向掠过整个立方体，98 个表面格块依次被创建。参数集中在 `src/rendering/config.js` 的 `INTRO_STYLE`，实现集中在 `src/main.js` 的 intro 区块（`armIntro()`、`updateIntro()`、`settleIntro()`）。

- **触发**：`leaveHome()`（新游戏/继续游戏，主页收起后）与 `beginRun()`（设置里的重新开始、结算面板的再来一局）。启动时的 `resetGame()` 不播——那时玩家还在主页。
- **排序**：在**第一帧真正可见时**把每个格块的世界坐标投影到屏幕，取 `(x + y) + depthBias·z` 排序，`x`、`y` 为 NDC（`+y` 向上）。深度项让远面比近面晚约一个节拍，波次因而**一次横扫当前可见的多个面**，不是六个面各自播放。
- **单块**：`opacity 0 → 1`；`scale 0.72 → 1.04 → 1`（0.62 处达峰，之后只回落，不振荡）；沿该格块面的法线从内缩 `inset=0.42` 回到齐平（棱/角块是相邻面法线的合成，即立方体径向）。
- **节奏**：单块 `duration=0.19s`（160–220ms）；斜向顺序切成 26 个波次、相邻波次 `bandStagger=0.032s`（25–40ms），同波次内约 4 格同时开始并有 ≤12ms 的确定性散开（由格坐标哈希，不用随机数）；整段 `total≈1.05s`（0.8–1.2s）。**98 格逐格 25–40ms 需要 2.4–3.9s，装不进 1.2s**，所以“相邻”按波次计。
- **主次**：已占用（彩色）格块晚 `occupiedDelay=0.05s` 出现，并在自己的峰值处获得一次 `shine=0.22` 的轻微亮度提升，落地前归零。
- **结束**：`settleIntro()` 从 arm 时保存的副本显式恢复 transform 与**共享材质实例**（不是动画用的逐块 clone），再走一次 `applyTileMaterials()`；因此结束后格块的位置、尺寸、材质与齐平状态与动画前完全一致。
- **输入**：播放期间由 `syncPause()` 统一上锁（旋转、拖拽、放置、道具、键盘同一把锁），播完统一解锁。
- **取消**：回主页（`openHome()`）与页面隐藏会直接结算到位；连续重开时 `armIntro()` 先 `settleIntro()` 再开始，**永远只有一轮**。实现只用 rAF 循环驱动，没有 timer 或 tween，不会残留。
- **减少动态效果**：`prefers-reduced-motion: reduce` 时为 0.18s 的整盘淡入，不做逐格弹性、不移动也不缩放任何格块（arm 时读取该偏好）。
- **不写入规则层**：波次只读棋盘已经生成的 `occupiedColors`、格块自身变换与相机，不复制第二套棋盘状态、不逐格改游戏数据；`__voxalblast.intro()` 提供只读回读（含每个格块的位置/缩放/材质完整性计数）供自动化核对。

## 7. 计划/待验证（不是已实现验收）

以下结论仅靠本轮静态阅读不能成立，需真实浏览器或设备验证后再改为“通过”：

1. 触屏按住、转面、取消、拖回候选区的手感和误触率；
2. 所有响应式断点下实际排版、遮挡与安全区；
3. 弱透视构图、网格视觉水平度与微调边界的主观观感；
4. 触感、音效解锁、页面失焦及嵌入式 WebView 的真实兼容；
5. CrazyGames 容器的暂停/恢复生命周期；
6. 道具瞄准态是否应补齐键盘翻面（当前未实现）。

本轮未运行构建、测试、探针或浏览器，因此不沿用历史文档中的“实测通过”作为当前版本结论。
