# VoxalBlast 荣誉与纪录系统

> v0.7.0 实现基线。依据 scoring.js、honors.js、records.js、tiers.js、platform/crazygames.js。（v0.7.0：美术方向改为木质田园，规则与数值未变）

## 1. 结算职责

Board 提供六面满线结果；scoring 计算积分；honors 判定荣誉与反馈等级；main 维护当前局；records 保存已结束局。规则与公式见 [02](02-核心规则与数值.md)。

## 2. 当前荣誉

| ID | 条件 | 奖金 | 播报 |
| --- | --- | --- | --- |
| TRIPLE | 单次 ≥3 线 | 150 | 是 |
| QUAD | 单次 ≥4 线 | 500 | 是 |
| PENTA | 单次 ≥5 线 | 1500 | 是 |
| HEXA | 单次 ≥6 线 | 4000 | 是 |
| TRIFACE | 单次 ≥3 面 | 600 | 是 |
| PERFECT_TWELVE | 单次 ≥12 线 | 20000 | 仅记录 |

阈值逐级累计触发，奖金相加；只选择一个主横幅，按 priority 降序，再按奖金排序，其他为次级徽章。不以“只发最高档奖金”理解。十二线是理论纪录项，不承诺正常游戏中可频繁获得。

## 3. 反馈层级

无消除 L0，单线 L1，两线 L2，三线 L3，四线或三面 L4，五线以上或四线且三面 L5。L5 带 0.6 倍、400ms 的短时动画减速，不改变输入规则。视觉参数在 rendering/config.js。

## 4. 本地纪录与阶位

纪录键为 voxalblast.records.v1，包含历史最高分、周最佳、个人维度、荣誉次数和最近十局。个人维度包括最长链、单次线数、单次面数、点亮面数、净面、净体。

历史最高分在 endGame 记录一局后更新，不是实时追随当前 SCORE。因此正在玩的分数高于 BEST 可能是正常行为。周边界在当前代码中固定为周一 09:00 UTC；这描述的是仓库算法，不代表本轮重新确认了外部平台赛季规则。

阶位名称和映射机制已有，但 TIER_CUTS 全为 null，界面显示待校准。六面制霸徽章仍未实现；点亮面数作为纪录维度存在。

## 5. 平台全球榜

已有可选适配和灰态入口，不是已交付在线排行榜。运行时依赖外部提供 CrazyGames.SDK。当前可用判定检查 VITE_CRAZYGAMES_LEADERBOARD=on 和 SDK 的 submitScore 方法；分数加密读取 VITE_CRAZYGAMES_SCORE_KEY，缺失时可能仅提交明文参数。显示入口再调用可选 showLeaderboard。

这些 API、授权、加密消息格式和实际提交均未完成平台验收；仅设置环境变量不能证明集成正确。也没有自建排行后端、客户端全球榜查询或云端续玩。
