# VoxalBlast 特效设计与庆祝感升级

> **文档状态：设计提案 v1.0，待美术评审与分轮实现。**
> 实现基线：当前工作区 **v0.8.22**。§2 为静态核对的现状；其余章节为目标设计，不代表已经实现或实机验收。所有新增时长、数量、尺寸与性能预算都是首轮调试建议值。
> 本轮只新增设计文档与导航，不修改玩法、代码、素材或游戏版本。未提供新的特效参考视频，方向依据现行 [05 美术规范](05-美术方向与视觉规范.md)、[03 交互](03-交互与表现需求.md)、源码及实际背景资产制定。

## 0. 设计结论

**让每次消除像完成一件漂亮的木作，让精彩操作像花园庆典里的一声喝彩。**

保留「暖木玩具 + 彩漆积木 + 奶油纸 UI + 阳光田园」的主体，新增统一的**手作纸彩、短彩带、压印星花、木牌授奖**语言。节日感首先来自有层次的仪式与节奏，而不是全屏粒子、强闪白、猛烈震动。

- **日常操作：精致、轻巧、确定。** 拿起、落下、消一线都能感到响应，但不处处撒彩纸。
- **精彩操作：先看懂成果，再获得喝彩。** 消线位置 → 多线/跨面关系 → 主荣誉 → 分数确认，主次清晰。
- **稀有时刻：有真正的庆祝。** 高档消除、连击里程碑、新纪录才出现更完整的彩带与礼花。
- **常驻环境：仍然安静。** 保留田园的呼吸空间，不把全局做成一直营业的嘉年华。

### 首批最值得做的三件事

1. **重做单线到多线的消除节奏**：把当前「光束 + 双星 + 粒子」收敛成「短亮边确认 → 彩漆退场 → 少量纸彩散开」，先提升每天都会看到的手感。
2. **建立 L3–L5 的庆祝层级**：大操作不只是粒子翻倍，而是增加彩带构图、跨面呼应与一块主荣誉木牌。
3. **补齐新纪录结算仪式**：结算页给一次温暖、完整、可立即跳过的庆祝，而不是只有 NEW BEST 文案。

暂不改开场、相机、棋盘材质、背景插画与 UI 布局；先用最小范围做出一组可对比的效果样板。

## 1. 调性与边界

### 1.1 主风格：木作花园庆典

| 维度 | 应该像 | 不应该像 |
| --- | --- | --- |
| 材料 | 哑光彩纸、短布带、木牌、纸质压印 | 镜面金属、玻璃碎片、能量晶体 |
| 动势 | 轻敲、舒展、扇形抛起、翻面飘落、一次弹性回位 | 爆炸冲击、长距离喷射、持续震荡、无规则旋涡 |
| 光 | 奶油色短高光、暖日光下的星花 | 霓虹光柱、全屏白闪、整盘泛白 |
| 庆祝元素 | 圆角纸片、短彩带、少量圆润星章 | 火焰、烟雾、闪电、密集烟花、金币雨 |
| 情绪 | 「做得漂亮」「这手很精彩」 | 战斗破坏、紧迫警报、失败惩罚 |

**节日感 ≠ 绑定某个节日。** 默认是一年四季都成立的花园庆典，不预设圣诞、新年、周年庆活动；具体节庆只作为以后可替换的装饰皮肤，不新增活动任务或奖励系统。

### 1.2 与现行规范的关系

- 98 个唯一格、六面共享棱角、0.94 方块边长与齐平关系不变。**局内放置和消除不挤压、抬升或炸飞棋盘实体**；弹性发生在独立特效或 UI 上。现有开场临时变换是单独的已实现流程，本提案不扩展该例外。
- 空格仍是木色，占用仍是原有彩漆；不得为过节把游戏块统一改成红金、黄绿或其他易混淆颜色。
- 沿用「游戏内容最饱和」：局部消除可短暂继承来源漆色；周边庆祝纸彩统一低一档饱和，背景与 UI 不新增大面积高饱和装饰。
- 奶油金只用于小星花、纸章边与短亮边，不能把空木格染成“金色奖励格”。这不是对方块木色带禁令的豁免。
- 现有开场约 2.83 秒的「冷灰蓝底漆 → 停一拍 → 正式上色」完整保留；底漆阶段不能出现游戏漆色或庆祝彩纸，不额外延长输入锁。
- 不新增消除规则、分数、连击倍率、荣誉、道具补给、复活或在线排名。表现只消费现有结算结果。

## 4. 庆祝强度阶梯

### 4.1 沿用当前判定，不另立一套阈值

按 L5 → L0 优先命中；线数指本次正常落子结算的线数，面数指本次实际消线面数。

| 级别 | 现行条件 | 目标画面 | 纸彩总量上限：标准/低配 | 庆祝尾段建议 |
| --- | --- | --- | ---: | --- |
| L0 | 0 线 | 漆面短确认，无礼花 | 0 / 0 | 无 |
| L1 | 1 线 | 一次短线带 + 少量纸屑 | 6 / 3 | ≤0.55s |
| L2 | 2 线 | 两线呼应 + 一次小星花 | 12 / 6 | ≤0.70s |
| L3 | ≥3 线，且未命中更高档 | 主荣誉木牌 + 局部扇形纸彩 | 24 / 12 | ≤0.90s |
| L4 | ≥4 线，或 ≥3 面，且未命中 L5 | 跨面呼应 + 两束短彩带 + 星章 | 40 / 20 | ≤1.20s |
| L5 | ≥5 线，或 ≥4 线且 ≥3 面 | 一次双侧礼花 + 大星章/主荣誉；棋盘中心留空 | 64 / 28 | ≤1.60s |

- 数量是**整次落子总量**，不是每格/每线数量。不同视觉形态替换占用预算，不能按线数无限相乘。
- 上表是新增庆祝尾段，不取代现有主横幅展示时间：small/name/large/full 当前为 700/900/1400/2200ms。文字可以在粒子退场后安静停留，不用一直撒纸彩。
- L5 已有 0.6 倍/400ms 动画慢放。本提案不扩大慢放、不添加顿帧或输入锁；样板先保留该行为。表中验收窗口按**实际墙钟时间**计，新增动画应明确时钟归属，不能被慢放意外拖长。
- 普通消线建议取消大幅相机震动，用局部星花和纸带完成冲击；高档也不以加大抖动为卖点。首轮可比较零震动与轻量原版，选型后只调表现参数，不改相机基础取景与命中投影。

### 4.2 连击不是另一套消除等级

连续有消除的正常落子使 chain 增长，无消除落子归零；道具不增加也不打断 chain。

- 普通连击增长只更新 CHAIN 牌，不让每一手自动升级成 L5。
- 5/10/15/20 的里程碑使用同一套纸结，分别增加 1/2/3/4 个印记；不是不断增加粒子数量。
- 同手发生高档消除与里程碑：主庆祝仍用现有消除等级；里程碑以 HUD 结饰出现。可将少量纸彩移到 HUD 附近，但总预算不叠加。
- L1/L2 单独遇里程碑时，HUD 优先用纸结与静态印记强调；如需纸彩，从该等级整次落子的总预算中分配，不额外叠加。FX-15 的 500–800ms 是 HUD 纸结/印记展示窗口，纸彩仍分别在 L1 的 0.55s、L2 的 0.70s 内退场，不能用 HUD 停留时间延长飞行尾段。
- 主横幅文案优先显示真实荣誉名，附属徽章沿用现有返回。`PERFECT_TWELVE` 当前不做主横幅，但可能进入小徽章行；本提案不偷偷改变该口径。

## 5. 四组关键效果分镜

### 5.1 放置与单线：从「确实放好了」到「这一线完成了」

`t=0` 定义为规则成功结算。逻辑占用、分数和存档按当前流程更新，不等以下演出完成。

| 相对时间 | 画面 | 注意 |
| --- | --- | --- |
| 0–70ms | 落子范围出现低亮奶油色边缘确认 | 无消除只做这一条短确认并收尾 |
| 40–140ms | 命中满线一条窄纸光带展开，行/列方向清楚 | 不是高能光束；共享满棱不能把亮度叠两倍 |
| 80–220ms | 彩漆视觉退场，原木空位清晰露出 | 如需残像，用可丢弃的表现快照；不能回写已清除占用 |
| 120–360ms | 少量纸彩沿线两端散开，轻抛、翻转、缩淡 | 优先向棋盘外缘，不从每格独立喷射 |
| 180–400ms | 一个总分跳字收束，下一步操作始终可继续 | 触发新拖拽即淡出遮住预览的残像 |

目标观感是「啪嗒、刷、叮」，不是「炸开一团之后才发现格子空了」。主动作短，尾段在周边轻落；纸屑不再拼成候选块轮廓。

### 5.2 多线/跨面：把六面玩法优势做出来

1. 同批所有真实满线先确认；行与列通过方向辨认，不额外发明颜色分类。
2. 对可见的不同面做 0–60ms 轻微呼应；逻辑仍同批结算，没有连锁落下或重力。
3. 面内线带贴合面坐标；共享格散片按晶格去重。线的说明可各自保留，实体退场只出现一次。
4. 背面消除不能透过立方体画满亮线，也不自动转镜头。保留真实遮挡，用现有 `N LINES / M FACES` 信息解释总成果。
5. L3 局部扇形纸彩，L4 加短带，L5 才从两侧形成完整庆祝弧形。中间棋盘、手指落点与候选保持干净。
6. 荣誉木牌在不挡落点的 HUD 周边展开，只有一块；手机空间不足时改紧凑横条，不把棋盘推小。

### 5.3 道具：像四种不同工具，不像四种爆炸

- **Hammer**：一记短敲，单点纸星。删除的是漆色占用，不是把木方敲出坑。
- **Rocket**：一条窄纸带沿当前 Row/Col 方向快速打开，只强调目标行/列与实际清理格；无拖尾火焰。
- **Bomb**：一个贴面小纸花朝有效 2×2 四角展开，最大不超实际裁边后的范围；不能用大圆环暗示圆形范围伤害。
- **Refresh**：发生在候选纸托内的换页，棋盘不变、不发光、不庆祝“必出好牌”。

瞄准轮廓在规则执行前显示完整有效作用域；执行成功只在实际删除格生成反馈。共享棱角的相邻面同步恢复木色，可用一次轻轮廓提示，不能复制第二份清理粒子。清理没有分数飞字、荣誉木牌、CHAIN 增长或 L1–L5 庆祝。

### 5.4 新纪录：结算页专属高潮

以 `endGame()` 记录本局后返回的 `summary.isNewBest` 为唯一入口：

1. **0–200ms**：成绩卡就位，最终数字与“再来一局”立即可见可用。
2. **150–400ms**：NEW BEST 纸章一次压印，边缘小星花出现。
3. **220–1000ms**：卡片左右两侧各一束纸彩向外上方抛起，再自然散落；不经过主分数和按钮。
4. **1000–1600ms**：彩纸完全退场，只留静态纪录星章与成绩。

纸彩上限标准 72、低配 28；不叠加局内遗留 L5。点击重开/关闭立即取消尾段。普通结算只做轻入场，不误播“胜利”；局中 SCORE 超过 BEST 也不提前冒出第二套全屏纪录庆祝。

## 6. 视觉元素、配色与制作规范

### 6.1 元素库：少而统一

| 元素 | 造型与运动 | 使用范围 |
| --- | --- | --- |
| 圆角纸片 | 2:1 / 3:2 两种比例，轻厚度，抛物线后受阻力下落 | L1–L5 与纪录；主力元素 |
| 短彩带 | 最多两段弯折，宽窄统一，不做长蛇形拖尾 | L4/L5、纪录 |
| 星花 | 圆钝四角闪点；一闪一收，不随机频闪 | 落子/工具/低档消除点缀 |
| 星章 | 圆润五角纸章或木牌内纸印，无金属镜面 | 荣誉与纪录，不每条线各放两个大星 |
| 线带 | 两端软圆、窄、低亮，依附消除方向 | 所有消线/火箭 |
| 纸结与小旗 | 静态为主、最多一次舒展 | CHAIN 里程碑/可选主页装饰 |

粒子尺寸区分屏幕装饰与场景粒子：

- **DOM/CSS 纸彩**：短边建议 3–7 CSS px，不随 DPR 翻倍；尺寸上限取对应区域一格投影宽度的 18%。
- **fxGroup / quarks 的 3D 纸彩**：以世界单位制作，短边初值取一格边长的 6%–12%，随真实透视与缩放变化；默认相机下以约 3–7 CSS px 的表观尺寸作参考，不承诺全距离恒定像素。若需要校准，以发射点深度处的投影比例 `世界尺寸 = 目标 CSS px ÷ 每世界单位的投影 CSS px` 换算，并钳制到一格边长的 18% 以内；不每帧反向缩放抵消相机运动。
- 长彩带目标不超过一格投影宽度。以实际小屏检查，若纸片小到亚像素闪烁则减少或取消，不堆更多碎屑。

### 6.2 建议色板（装饰色，不替换游戏色）

| 色名 | Hex | 用途 |
| --- | --- | --- |
| 奶油纸 | `#FFF1D4` | 光边、纸章底、少量高明度纸片 |
| 蜜蜡金 | `#E7B75F` | 小星章、纸带边；不是金属或新的占用色 |
| 玫瑰纸 | `#C98699` | 低饱和庆祝纸彩 |
| 晴空纸 | `#8DBDD3` | 低饱和庆祝纸彩 |
| 鼠尾草纸 | `#A5BBA1` | 花园气质的辅助色 |
| 树皮墨 | `#452E13` | 纸章文字与边缘；沿用现行 UI 主文字 |

单次庆祝最多三种纸彩色 + 奶油色，避免六色随机雨。局部散片如继承来源漆色，应压低饱和度并立即衰减；不能拿随机色给每颗粒子染色。灰度下仍应靠线方向、形状和文案读懂结果。

### 6.3 制作方式

- 优先复用低复杂度几何、SVG 路径与 CSS；特效不需要新生成式图片，不引入在线资源依赖。
- 3D 纸彩跟随统一场景明暗；HUD 纸章沿用 UI 的上亮下暗与木边体系。禁止另画一套逆向高光。
- 纸片主体不靠 additive 发光；小闪点才允许有限亮度增强。不得为了星花调整全局曝光或提高 Bloom，把棋盘洗白。
- 文字、分数、数量和荣誉名始终是真实 DOM 文本，不烘焙进图片。
- 随机性只用于受限位置、角度、速度；颜色、形状、寿命有有限集合。视觉随机流与发牌随机流分离，测试可固定种子。
- 每个基础元素先过「放大轮廓、实际尺寸、240px 宽缩略图、灰度」四项检查，再复制到不同事件。

## 7. 编排、遮挡与生命周期

### 7.1 一次落子一个主事件

建议在表现层构建一次只读的效果描述，汇总已有的 `lines / facesHit / level / honors / score / chain`；不新增第二套计分或消线判断。

1. **操作信息优先**：当前落点/道具范围/系统模态控件 > 结果可读性 > 荣誉文字 > 粒子装饰。
2. 同手多个荣誉只播 `primary`；其他按现有规则进入徽章行。一个分数总计、一次主要成功音、一次纸彩爆发。
3. 同手里程碑跟随主事件，不再额外启动全屏礼花或长提示队列。
4. 连续快落子：每次保留短线确认与正确数字；庆祝横幅只保留当前最高优先级或更新合并，不无限排队。新增粒子不足预算时少发，不累积延迟发射。
5. L4/L5 的侧边装饰建议最多每 1.2 秒发射一次；冷却只省略装饰，不能吞掉分数、荣誉、消线提示或真正的输入。
6. 局终时取消局内尾段，由结算接管。不能出现 NEW BEST 后又迟到一个局内荣誉横幅。

### 7.2 空间与输入保护

- 线带贴棋盘面；纸彩抛出后进入世界空间。不能把生成时的世界坐标当作局部坐标，导致翻面后效果漂移。
- 使用 `cellToWorld`、`lineCenterWorld` 与正确的当前矩阵；表面偏移参照实际几何及 `feedbackSurfaceOffset`，不抄旧版尺寸注释。贴面残像应跟随面或在新手势开始时快速退场。
- 3D 装饰尊重遮挡，不从背面穿透；独立 HUD 庆祝层应 `pointer-events: none`、`aria-hidden`、不可聚焦。
- 任何时刻装饰不能盖住 SCORE/BEST 数字、候选抓取区域、道具库存、撤销按钮或当前落点轮廓。
- 侧边发射点由实际棋盘/HUD/候选矩形与安全区计算，不硬编码为画面底部。短横屏右边已有候选时，少发或移到左侧留白，不能为了礼花缩小棋盘。
- 无可用留白就降级为小星章；不以“节庆版”为由遮盘。

### 7.3 时钟与回收

- 普通局内 VFX 不锁输入、不延迟结算；现有开场输入锁与道具冷却保持原样。
- 使用受控动画循环/可取消的 DOM 动画；不散落无归属的 setTimeout。建议用运行批次标识使过期回调失效。
- 世界空间临时对象接入现有 `transientEffects`、`particleSystems` 与清理入口；新增 DOM 纸彩也须注册销毁，不让 WebGL 清理后留下另一套动画。
- 页面隐藏、主页、重开、局终、设置等切换应按状态清理装饰或稳定收束；恢复时不追赶/补播。道具撤销应能取消该次清理残留。
- 共用几何/材质集中持有；短命实例归池或释放，不能每次 dispose 被别的效果复用的共享资源。
- 所有降级与清理只影响表现，不写棋盘、计分、存档或平台层。

## 8. 声音、触感与减少动态效果

### 8.1 声音与触感建议

| 事件 | 声音方向 | 触感方向 |
| --- | --- | --- |
| 放置 | 短木音/轻敲 | 保持轻量单脉冲 |
| 单线/双线 | 木音后接一个明亮短音，双线可为双音 | 不按每条线叠振 |
| 高档荣誉 | 2–3 音短上行，顶档加入轻铃尾音 | 同一事件最多一组 |
| 道具 | 木槌短敲 / 纸带轻扫 / 纸花轻扑 / 换页 | 力度低于高档荣誉 |
| 新纪录 | 一次短庆祝和弦，约 0.6–0.9s | 关闭/不支持时无影响 |
| 连击中断/局终 | 温和收束，不用低沉失败警报 | 不加强负反馈 |

本表为方向，不代表已交付音频。复用现有声音/触感开关与设备能力判断；避免 place/honor/chain 同帧满音量叠加。静音或无触感时，视觉必须独立成立。不要以浏览器支持声明代替真机听感/触感验证。

### 8.2 Reduced motion 是独立维度

`prefers-reduced-motion: reduce` 不等于低性能，两个维度需分别处理：

- 保留静态结果、分数、主荣誉与合法性提示；改用 100–180ms 淡入淡出，不删必要信息。
- 禁止纸彩飞行、旋转彩带、镜头震动、闪烁与新增慢放；现有 L5 慢放需在实现时核对并补齐该偏好的抑制路径。
- 开场沿用现行 0.18s 整盘淡入；新纪录只出现静态纸章与文字。
- 不使用高频闪白；短亮边仅单次变化。静态替代不能只用颜色编码成功/失败。

## 9. 性能预算与工程接入建议

以下是待验证的预算，不是当前性能成绩。

| 项目 | 标准档 | 低配档 |
| --- | --- | --- |
| 同屏活动纸彩总上限（含重叠事件） | 96 | 40 |
| 单次 L5 / 新纪录上限 | 64 / 72 | 28 / 28 |
| 连续长彩带 | 最多 2 条 | 关闭，用短纸片代替 |
| 常驻环境粒子 | 默认 0 | 0 |
| DOM 庆祝主横幅 | 1 个主横幅 + 紧凑附属徽章 | 同左，不按粒子建立大量 DOM |
| 新增后处理 Pass | 0 | 0 |
| 新增外部位图/音频包 | 首轮目标 0 | 同左 |

按同机、同种子、同分辨率、同质量档录制 30 秒固定操作脚本，记录无特效与升级版的 CPU/GPU 或帧时间可用指标。首轮目标：标准档 P95 帧时间增量≤2ms，低配≤3ms；60Hz 目标设备尽量维持每帧 16.7ms 内。若基线本就不足 60fps，应同时报告基线与增量，不宣称已达标。**物理低端手机必须单列实测。**

超预算降级顺序：移除环境装饰 → 移除长彩带 → 降纸彩数量 → 缩短尾段 → 只保留线带/纸章/数字。不能先牺牲落点、候选、原木/彩漆辨识与交互采样。

### 接入位置（建议，不是本轮代码变更）

- `config.js`：保留 `FEEDBACK_STYLE` 作为等级表现映射，新增纸彩预算、纸章样式、无障碍与主题参数；不修改 `honors.js` 定级条件。
- `main.js / spawnClearEffects`：正常消线唯一分发入口；把每线的粒子累加改为整次事件统一分配预算，再分给各可见方向。
- `showHonorBanner / showScorePop / updateChainHud`：合并表现优先级、控制数字与文字占位。链里程碑只读取既有运行态。
- `emitItemBurst` 与道具确认路径：独立工具效果配置，不复用正常落子庆祝等级或分数路径。
- `renderGameOver(summary)`：纪录纸章与侧边礼花；复用既有 `isNewBest`，不新增历史最高分判定。
- 按需抽出 `src/rendering/celebration.js` 等表现模块，**模块名为建议，当前未创建**。不要为一轮特效顺带改全项目结构。
- 保留 [threeCompat.js](../../src/rendering/threeCompat.js) 兼容桥。quarks 的 `emissionBursts[].count` 必须传 ValueGenerator（如 `ConstantValue`），不是裸数值；粒子异常不能让主渲染循环静默停摆。资源回收、重复重开、隐藏恢复必须有回归证据。
- 现有 `quality.lowPower` 是初始化时选择，不等于实时 FPS 自适应；本期先沿用分档，不承诺自动性能调节。

- [ ] 同状态记录标准/低配的帧时间与活动对象峰值；反复触发、重开后对象与资源数回落，不线性累积。
- [ ] 物理手机触控、声音与触感单列结果；浏览器移动视口不冒充真机。

### 11.4 后续实现轮的工程门禁

- 按涉及范围运行规则测试、构建、消除/道具爆发与清理回归、相关交互探针；不能直接搬用 04 的历史通过数。
- 使用固定 fixture/视觉种子在隔离测试浏览器中触发高档场景；高线数组合不等于真人常见频率。现有截图脚本不默认覆盖全部新 VFX，需要按实现补探针或录屏场景。
- 纯表现轮不改 `src/game/**`、`src/platform/**`、计分、存档协议、发牌随机源。若确有行为变更，另立功能任务。
- 对比本轮开始时的工作区，区分既有改动与本轮变更；`git diff --check`、链接检查及无运行异常是基本门禁，不等于美术验收通过。
