# VoxalBlast MVP 验收清单

> 用途：策划、程序、美术和 QA 的联调基线

> 版本：MVP v0.4.1

## 棋盘与规则

- [ ] 棋盘为一颗六面体，6 个面均参与放置；每面为 5×5 网格。
- [ ] 方块只能放在六个面的表面，立方体内部/中心不可放置。
- [ ] 每个面每格最多放置一个单位方块，越界或重叠时不可确认。
- [ ] 方块放置后无重力、无自动下落、无位置漂移，固定在面上并向外凸起一个单元厚度。
- [ ] 每个面的行线（固定 v、u 全满）与列线（固定 u、v 全满）均能正确识别。
- [ ] 同次落子消除多条线时，所有线一次结算。
- [ ] **跨面连爆（v0.3 起，核心回归项）**：一次落子后扫描**全部 6 个面**结算满线。因棱上 1 格被 2 面共享、角上 1 格被 3 面共享，同一次落子可能同时在多个面成线，这些线必须全部结算——不得只在放置面结算。等价断言：任意一步落子完成后，**6 个面上都不存在残留的已满线**。
- [ ] 交叉线共享格子时不重复删除方块，但每条线都计数。
- [ ] 三个当前方块在任意面均无合法放置位置（扫描全部 6 面）时触发 Game Over。

## 方块与操作

- [ ] 每回合提供 3 个方块。
- [ ] 方块为平面 2D 拼块，提供 **10 类**（单点/直线 2/3、田字、L/J/T/S/Z、三格转角）；最长直线为 3（v0.2.24 移除 5 格直线；v0.2.31 按制作人拍板移除 4 格直线）。
- [ ] **开局预置方块（v0.2.31）**：开局不是空壳——`OPENING_LAYOUT` 按**每面格子数目标**在初始可见的正面/顶面/右侧面预置方块（+z 7 格 / +y 3 格 / +x 3 格，实测合计 15~18 格），方块取自同一候选池（同形状、同颜色），`__voxalblast.board().cells` 的 color 必须全部落在 `__voxalblast.shapes()` 的颜色集合内。等价断言：开局 `score === 0`、`totalLines === 0`、**6 个面都不存在已满线**、格子互不重叠且全在外壳上（且只落在 +z/+y/+x 三面上）；开局 3 个候选至少有一个可放置（至少 3 个面完全为空）；新开一局必须重新随机（不是固定盘面）。
- [ ] 备选方块始终以平面正视、正面朝向玩家展示（不随立方体旋转而倾斜）。
- [ ] 拖动空白区可旋转立方体；松手后必定停在"某个面正对玩家"的姿态：超过阈值（约 30°）转到下一个面，未超过则弹回起手面，并保留偏航/俯仰每轴 ≤8° 的轻微偏摆。
- [ ] **手势轴固定、不随六面体旋转（v0.2.27 核心回归项）**：先偏航到侧面再上下滑，仍然是绕屏幕横轴翻面（正对的面必须改变）；先自转 90° 再左右滑，仍然是绕屏幕纵轴偏航（正对的面必须改变）；先偏航再窄带上下滑，仍然是绕屏幕法线的平面内自转（正对的面不变）。等价断言：任意姿态下 `ΔQ = base_after · base_before⁻¹` 精确等于绕对应世界轴的 90° 旋转（实测 `angle=90.0000°`、误差 < 1e-9）。
- [ ] 旋转方向跟手：右滑正面往右走、六面体范围内下滑正面往下走、窄带下滑屏幕平面内顺时针自转（v0.2.26 的整体取反已撤销）。
- [ ] **Z 自转精确归正（v0.2.28 加强）**：先用偏航/俯仰手势制造非零 `tiltYaw/tiltPitch`，再从窄带上下滑动；停稳后 `tiltYaw === 0`、`tiltPitch === 0` 且渲染姿态 `pose` 精确等于 `base`，`base` 的 Z 台阶仍为 90° 整数倍。未过阈值的 Z 手势同样清除旧偏摆并弹回裸网格姿态，面不得有肉眼可见歪斜。
- [ ] **松手不吞掉手指已经划出来的旋转（v0.2.30 回归项）**：任意轴、任意姿态下，连续同方向滑动**每次都翻面**，不存在"死方向"；俯仰可连续翻过极点把背面转到前面（`+z→+y→−z→−y→+z`）；拖动过程中渲染出来的角度**不超过"起手姿态 ± 一个面"**。等价断言：手势进行中（手指仍按下）取一次姿态、松手停稳后再取一次，两者夹角 ≤10°。v0.2.29 实测为"重复下滑 拖动 105.5° → 弹回 89.5°""长滑 拖动 136.4° → 弹回 38.4°"，均为缺陷。同时仍须满足"未过阈值的短滑精确弹回起手面"。
- [ ] 一次手势只认一个轴：左右滑动只绕屏幕纵轴（Y）偏航；上下滑动在六面体水平范围内只绕屏幕横轴（X）俯仰、在六面体水平范围外只绕屏幕法线（Z）自转；斜向滑动不合成两轴，另一个轴的角度保持不变。
- [ ] 一次手势在该轴上最多翻一个面；吸附动画中途重新按下不会出现角度抵消或画面抖动。
- [ ] **起手抖动不能吞掉整段手势（v0.2.29 回归项）**：按"起手先侧向偏移约 9px、随后竖直下滑 200px 以上"的路径滑动，必须按**俯仰**翻面（正对的面改变），不得出现"六面体完全不动"。等价断言：定轴由领先方向决定（领先 ≥1.2 倍且位移 ≥16px），松手角度 ≥ 阈值 30°。
- [ ] **翻面所需滑动距离与设备无关（v0.2.29）**：拖动→角度的标尺是**六面体自身在屏幕上的投影尺寸**（约 1/6 即翻一面），不再是画布尺寸。同一段约 115px 的横滑在 1120px 宽的桌面画布上必须翻面（旧的画布标尺需要约 185px，会弹回）；未过阈值的短滑仍必须精确弹回起手面。
- [ ] **丢失 pointerup 后旋转不得永久失效（v0.2.29）**：手指按下并滑出一段后，令页面进入隐藏态（`document.hidden = true` + `visibilitychange`）或窗口失焦，之后**新的**旋转手势必须照常生效（旧版本 `viewDrag` 残留会让旋转彻底失效、而放置仍正常）。
- [ ] **候选方块放置朝向与候选区一致（v0.2.28 修正）**：依次在中立、Z 自转 90°/180°、偏航及俯仰姿态下，把 L/J/S/Z/T 等非对称候选拖到当前面；落子后的视觉轮廓必须与候选槽位**完全一致**，不得随面旋转、上下翻转或镜像。可用 `__voxalblast.placement()` 断言 `uAxis.dx > 0`（左上原点的 `+u` 指向屏幕右）与 `vAxis.dy < 0`（NDC 中 `+v` 指向屏幕下）在所有姿态成立；不能再用旧的 `vAxis.dy > 0` 错误断言。
- [ ] "还有没有位置可放"按 6 面 × 4 个平面内朝向判定，不因只差一个侧向朝向而误判 Game Over。
- [ ] 六面体是主要操作区：默认取景下立方体在中央画布内完整可见且占满约八成（PC 按高度、移动端按宽度），左右仍留有可起手自转的窄带，不被顶部信息条、候选区或屏幕边缘裁切。
- [ ] 鼠标拖拽能顺滑跟随并自动吸附到当前前面网格。
- [ ] 合法落点有半透明预览；非法落点有明确反馈且不能放置。
- [ ] 开始拖拽后，整个候选方块区切换为取消放置区：候选与道具行弱化，**取消卡片（×/Cancel 提示）实际可见地覆盖整个候选区**，其他候选方块不可选择（v0.2.17~v0.2.24 期间卡片因类名遗漏未显示，v0.2.25 已修复，回归时必须同时断言"可见"而非只断言取消生效）。
- [ ] 将方块拖回取消放置区时有明确的高亮和吸附反馈，松开后方块返回原槽位。
- [ ] 主动取消、非法落点松开和拖拽中断都不会消耗方块、计分、推进回合或触发消除判定。
- [ ] PC 端 `Esc` 或右键可以取消当前拖拽，主要取消方式仍为拖回候选方块区。
- [ ] 方块朝向固定，不可由玩家旋转；无 X/Y/Z 方块旋转按钮，WASD 不旋转方块，也无镜头复位入口。
- [ ] 旋转立方体（而非相机）时棋盘大小保持稳定；滚轮缩放全程可用。
- [ ] 单局采用顶部信息条（左 SCORE 胶囊 + 右设置，开发版版本号居中悬浮且正式版移除不改变布局）+ 大面积中央立方体 + 底部候选方块行 + 道具行（候选在上、道具在下）；顶部不显示游戏名。
- [ ] 竖屏手机：顶部 SCORE 胶囊 + 设置，其下为候选方块行与道具行（候选在上、道具在下），再下是占满剩余高度的中央立方体；立方体不贴边不被截断（v0.2.25 起按现状验收，与桌面端的"棋盘在上、候选在下"顺序不同）。
- [ ] 手机版设置和顶部条不会遮挡立方体或截断方块拖拽。
- [ ] PC 端鼠标拖拽、滚轮和键盘操作完整可用。
- [ ] 竖屏手机端支持触摸拖拽与旋转立方体的触摸操作。
- [ ] 移动端触控区域足够大，不能依赖悬停或键盘快捷键。

## 道具（局内配额）

- [ ] 每局初始道具配额为换批 ×2、锤子 ×1、火箭 ×1、炸弹 ×1；图标行展示剩余数量角标，数量 0 或互斥态下置灰不可用。
- [ ] 换批重抽 3 个候选，且不与旧手牌完全同序同形；重抽后仍全无可放位置时正常进入 Game Over。
- [ ] 锤子只能点选当前面上的已占用格敲除 1 格；火箭清除当前面上的整行或整列（可切换行/列）；炸弹清除当前面上锚点向 +u/+v 延伸的 2×2 区域（越界处自动裁剪）。
- [ ] 道具不直接计分、不推进回合、不触发消除判定；目标选择可用 Esc/右键取消且不消耗。
- [ ] 拖拽、消除反馈、暂停与 Game Over 状态下道具不可用；本局道具不跨局保留。

## 提示与反馈

- [ ] （当前版本暂未实现）差 1～2 格候选线识别与高亮，作为未来增强保留。
- [ ] 候选提示不会遮挡棋盘或覆盖关键 UI。
- [ ] 放置、消除、Game Over 均有独立视觉反馈。
- [ ] 多线消除反馈明显强于单线消除。
- [ ] 消除反馈使用亮黄高亮、线色小方块与星星，不出现白色过曝或全屏泛白。
- [ ] 分数和倍率在消除后正确显示。
- [ ] 反馈播放期间不会吞掉下一次合法输入，也不会造成状态错乱。
- [ ] **五档反馈强度（v0.3.0）**：1 线 / 2 线 / 3 线（`TRIPLE`）/ 4 线或 3 面（`QUAD`/`TRIFACE`）/ ≥5 线或 `QUAD`+`TRIFACE` 同爆，分别对应 L1~L5，时长、震屏、粒子、音效、播报逐档增强；档位判定在 `honors.js#feedbackLevel()`，数值在 `config.js#FEEDBACK_STYLE`。
- [ ] **未消除的落子也有正反馈（v0.3.0）**：每格 10 分放置分照付，跳字以"安静版"单行 `+分` 出现，不与消除跳字抢焦点。
- [ ] **分数跳字最多四行（v0.3.0）**：`+分数` / `N LINES` / `M FACES`（仅跨面时）/ 荣誉名号（仅命中时）。
- [ ] **荣誉播报只弹一个主横幅（v0.3.0）**：稀有度最高者优先，其余以一行小徽章浮入；加分全部累加。
- [ ] **播报不遮挡棋盘、不阻断输入（v0.3.0）**：`#honor-layer` 位于棋盘上方信息带且 `pointer-events:none`；L5 允许 ≤400ms、约 0.6× 的顿帧，但期间输入照常生效。
- [ ] **连消链可见且断链有反馈（v0.3.0）**：链长 ≥2 才显示 `CHAIN ×N` 与进度条；落子未消除时胶囊灰闪约 0.6s 并播下沉音。
- [ ] **跨面消除的视觉正确（v0.3.0）**：一次落子跨面消除时，多面线条同批高亮消失，不出现"某面留一条满线不动"。
- [ ] **消除/道具爆发不得让画面停摆（v0.3.0 回归项）**：粒子批处理一旦抛异常，`animate()` 会在 `composer.render` 之前返回——**画面冻结而逻辑继续**（v0.3.0 实测命中：three r172 移除 `BufferAttribute.updateRange` 而 three.quarks 0.10.18 仍写它，导致第一次消除即冻屏）。`src/rendering/threeCompat.js` 桥接与 `emissionBursts[].count` 的 ValueGenerator 用法必须保持有效；**每次升级 three 或 three.quarks 后重跑本项**。
- [ ] **顶部信息条单行（v0.3.0 回归项）**：四胶囊 + 设置按钮不得溢出信息条高度、不得被挤到第二行（v0.3.0 实测命中：grid 显式列 + 稀疏自动放置会把胶囊挤到下一行，现用 flex + `order` 实现）。

## UI 与发布

- [ ] 首屏能看到立方体、分数、3 个方块和单一设置入口。
- [ ] 首屏只保留大号 SCORE、**次级 BEST 胶囊**与必要按钮，无 VOXEL GRID、LINES、说明段落、候选块编号或 VOXELS 等工程化文案。**（2026-09-11 修订：原条款"无 BEST"与荣誉与排行榜系统冲突，现允许 BEST——但字号必须小于 SCORE，不得抢焦点、不得在窄屏换行。）**
- [ ] 设置面板提供 Sound、Haptics 和 Restart Game，打开时暂停放置输入。
- [ ] 设置面板不含镜头复位项；重开与设置项均不改变视角。
- [ ] Game Over 显示本局分数并可一键重开。
- [ ] 桌面端常见分辨率下无 UI 重叠或溢出。
- [ ] 小屏窗口下立方体仍可完整操作。
- [ ] 页面刷新后可重新开始一局。
- [ ] 浏览器控制台无持续报错。
- [ ] CrazyGames Web 环境下鼠标、键盘和声音权限行为正常。
- [ ] 首屏不会被长时间 Loading、白屏或黑屏阻塞，加载阶段有状态反馈。
- [ ] 首屏优先加载立方体、基础方块和核心交互，非必要资源可延迟加载。
- [ ] 广告展示或页面失焦时游戏暂停，并停止接受放置输入。
- [ ] 广告结束或页面恢复后，立方体、方块、分数和回合状态保持一致。
- [ ] 不会因平台回调重复放置、重复消除或重复计分。
- [ ] 游戏运行时不加载图片贴图、视频背景、预制粒子图集或外部 3D 模型；六面体、方块、UI、材质与特效均由代码程序化生成。
- [ ] 已接入 `postprocessing` 的抗锯齿与阈值受控 Bloom，泛光不会淹没网格、方块轮廓和落点预览。
- [ ] 已接入 `three.quarks` 的批量程序化粒子，粒子沿被消除线所在的轴向发射，单线与多线反馈层级清楚。
- [ ] 高性能档具备柔和阴影、主光/补光/轮廓光和完整后处理；低端移动设备可降低粒子、阴影和后处理，核心规则与落点可读性不受影响。
- [ ] 初始化失败、资源失败和异常卡死均有可恢复路径。
- [ ] 发布前检查桌面端、竖屏移动端和低性能设备。
- [ ] **顶部三胶囊不换行（v0.3.0）**：`SCORE` / `CHAIN` / `BEST` 与设置按钮在 360px 窄屏仍同排显示，`BEST` 字号小于 `SCORE`，`CHAIN` 仅在链长 ≥2 时出现；版本徽标居中且**永不隐藏**（窄屏只缩字号）。
- [ ] **Game Over 面板含差值文案（v0.3.0）**：破纪录 `★ NEW BEST!`、差距 <10% `差 N 分破纪录`、否则展示本局最佳维度；并含六面制霸 `N/6` 进度、本局荣誉徽章行、统计行。

- [ ] **游戏内排行榜弹层（v0.3.0）**：本地最近 10 局条形图 + 个人最佳列表 + 荣誉收集计数 + 阶位徽章位；阶位未校准时显示"阶位待校准"，不得出现假数字。

- [ ] **本地纪录降级（v0.3.0）**：隐私模式或 `localStorage` 被禁时静默转为内存态，不阻塞开局，读档失败不崩溃。
- [ ] **周界对齐平台（v0.3.0）**：本地"本周最佳"按 **周一 09:00 UTC** 分界（CrazyGames 周赛季同点复位），跨时区不错位。
- [ ] **进入游戏先落在主页（v0.4.0）**：开机显示主页封面（品牌 + 最高分 + 主按钮 + 排行榜/设置），**不直接开一局**；顶部信息条与棋盘被封面完全遮挡（对设置齿轮位置做命中测试，取到的必须是主页元素）。
