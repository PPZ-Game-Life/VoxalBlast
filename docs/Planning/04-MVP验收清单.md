# VoxalBlast MVP 验收清单

> 用途：策划、程序、美术和 QA 的联调基线

## 棋盘与规则

- [ ] 棋盘严格为 4×4×4。
- [ ] 每个格子最多放置一个单位立方体。
- [ ] 方块可整体放入合法空位，越界或重叠时不可确认。
- [ ] 方块放置后无重力、无自动下落、无位置漂移。
- [ ] x、y、z 三个方向均能正确识别四格完整线。
- [ ] 同次落子消除多条线时，所有线一次结算。
- [ ] 交叉线共享格子时不重复删除方块，但每条线都计数。
- [ ] 三个当前方块均无合法姿态时触发 Game Over。

## 方块与操作

- [ ] 每回合提供 3 个方块。
- [ ] 至少实现直线、L 形、田字、立体形状等约 7 类形状，且不包含 4 格长条。
- [ ] 鼠标拖拽能顺滑跟随并自动吸附网格。
- [ ] 合法落点有半透明预览。
- [ ] 非法落点有明确反馈且不能放置。
- [ ] 开始拖拽后，整个候选方块区切换为取消放置区，其他候选方块不可选择。
- [ ] 将方块拖回取消放置区时有明确的高亮和吸附反馈，松开后方块返回原槽位。
- [ ] 主动取消、非法落点松开和拖拽中断都不会消耗方块、计分、推进回合或触发消除判定。
- [ ] PC 端 `Esc` 或右键可以取消当前拖拽，主要取消方式仍为拖回候选方块区。
- [ ] 三个候选槽位均显示真实 3D 方块组合，复用棋盘圆角几何、统一光照和顶/侧面明暗关系。
- [ ] 方块朝向固定，不可由玩家旋转；候选 3D 预览跟随主棋盘视角绕世界 Y 轴同步转向。
- [ ] 仅保留镜头水平环绕、滚轮缩放与 `VIEW RESET` 复位；画面中无 X/Y/Z 方块旋转按钮，WASD 不旋转方块。
- [ ] 视角环绕时棋盘大小保持稳定，不出现正对放大、对角缩小的跳变；滚轮缩放与 `VIEW RESET` 可恢复正常视野。
- [ ] R 键可恢复默认镜头视角，且不会重新开始游戏。
- [ ] 中间 3D 区域沿屏幕水平方向拖动可使相机绕世界 Y 轴旋转，棋盘始终完整可辨认。
- [ ] PC 横屏采用左侧状态、中央棋盘、右侧方块与操作区的三栏布局。
- [ ] 竖屏手机采用顶部平台栏与状态区、中央 3D 棋盘、棋盘下方 3 个方块、底部触摸操作区的布局。
- [ ] 手机版设置和平台栏不会遮挡棋盘或截断方块拖拽。
- [ ] PC 端鼠标拖拽、滚轮和键盘操作完整可用。
- [ ] 竖屏手机端支持触摸拖拽、双指缩放视角或等效触摸操作。
- [ ] 移动端触控区域足够大，不能依赖悬停或键盘快捷键。

## 道具（局内配额）

- [ ] 每局初始道具配额为换批 ×2、锤子 ×1、火箭 ×1、炸弹 ×1；图标行展示剩余数量角标，数量 0 或互斥态下置灰不可用。
- [ ] 换批重抽 3 个候选，且不与旧手牌完全同序同形；重抽后仍全无可放位置时正常进入 Game Over。
- [ ] 锤子只能点选已占用格敲除 1 格；火箭清除所选 x/y/z 方向的整条 4 格直线；炸弹清除锚点向坐标正方向延伸的 2×2×2 区域（越界处自动裁剪）。
- [ ] 道具不直接计分、不推进回合、不触发消除判定；目标选择可用 Esc/右键取消且不消耗。
- [ ] 拖拽、消除反馈、暂停与 Game Over 状态下道具不可用；本局道具不跨局保留。

## 提示与反馈

- [ ] 差 1～2 格候选线能被识别并高亮。
- [ ] 候选提示不会遮挡棋盘或覆盖关键 UI。
- [ ] 放置、消除、Game Over 均有独立视觉反馈。
- [ ] 多线消除反馈明显强于单线消除。
- [ ] 消除反馈使用亮黄高亮、线色小方块与星星，不出现白色过曝或全屏泛白。
- [ ] 分数和倍率在消除后正确显示。
- [ ] 反馈播放期间不会吞掉下一次合法输入，也不会造成状态错乱。

## UI 与发布

- [ ] 首屏能看到棋盘、分数、3 个方块和单一设置入口。
- [ ] 首屏只保留大号 SCORE 与必要按钮，无 VOXEL GRID、BEST、LINES、说明段落、候选块编号或 VOXELS 等工程化文案。
- [ ] 设置面板提供 Sound、Haptics、Reset View 和 Restart Game，打开时暂停放置输入。
- [ ] `VIEW RESET`/`RESET VIEW` 只恢复镜头，不改变棋盘、分数或方块供给。
- [ ] Game Over 显示本局分数并可一键重开。
- [ ] 桌面端常见分辨率下无 UI 重叠或溢出。
- [ ] 小屏窗口下棋盘仍可完整操作。
- [ ] 页面刷新后可重新开始一局。
- [ ] 浏览器控制台无持续报错。
- [ ] CrazyGames Web 环境下鼠标、键盘和声音权限行为正常。
- [ ] 首屏不会被长时间 Loading、白屏或黑屏阻塞，加载阶段有状态反馈。
- [ ] 首屏优先加载棋盘、基础方块和核心交互，非必要资源可延迟加载。
- [ ] 广告展示或页面失焦时游戏暂停，并停止接受放置输入。
- [ ] 广告结束或页面恢复后，棋盘、方块、分数和回合状态保持一致。
- [ ] 不会因平台回调重复放置、重复消除或重复计分。
- [ ] 游戏运行时不加载图片贴图、视频背景、预制粒子图集或外部 3D 模型；棋盘、方块、UI、材质与特效均由代码程序化生成。
- [ ] 已接入 `postprocessing` 的抗锯齿与阈值受控 Bloom，泛光不会淹没网格、方块轮廓和落点预览。
- [ ] 已接入 `three.quarks` 的批量程序化粒子，粒子沿被消除线的轴向发射，单线与多线反馈层级清楚。
- [ ] 高性能档具备柔和阴影、主光/补光/轮廓光和完整后处理；低端移动设备可降低粒子、阴影和后处理，核心规则与落点可读性不受影响。
- [ ] 初始化失败、资源失败和异常卡死均有可恢复路径。
- [ ] 发布前检查桌面端、竖屏移动端和低性能设备。

## 手感验收

- [ ] 新玩家 30 秒内能完成首次放置。
- [ ] 一局目标时长为 2～5 分钟。
- [ ] 中后期平均每 2～3 步出现一次差 1～2 格机会。
- [ ] 玩家能通过转动视角观察与规划解决大部分常规局面。
- [ ] 无解局的产生原因可理解，不出现明显的随机开局即死。
