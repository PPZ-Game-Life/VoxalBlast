## 3. 交互

- [ ] 任意姿态的 X/Y/Z 手势轴保持世界坐标，单次最多翻一面。
- [ ] 翻面所需滑动距离与设备无关：标尺是六面体自身在屏幕上的投影（约 1/6 即翻一面），桌面与手机上同一段滑动都能翻面。
- [ ] 起手侧向抖动不吞整段手势：先横向偏移再竖直下滑仍按俯仰翻面，不出现六面体完全不动。
- [ ] 短滑弹回、过阈值兑现、Z 自转清除偏摆；丢失 pointerup 后可继续操作。
- [ ] W/S、A/D、Q/E 与手势等价，按住不连发；按键旋转有中间帧不瞬移，最终落在 90° 网格；滚轮缩放可用。
- [ ] L/J/S/Z/T 在各面及自转后无镜像或上下翻转；候选斜视预览保持固定朝向。
- [ ] 轮廓外幽灵、合法落点预览互斥；偏心位置也跟手。
- [ ] 触摸抬升与鼠标抬升符合 03；吸附后相对位移、撞占用粘滞和反向回归正常。
- [ ] 候选/道具取消区、Esc、右键、主页、设置、隐藏、失焦均不残留幽灵或误消耗。

- [ ] 六面格槽与实体壳清楚；占用共享格后各面槽面均隐藏，不遮挡彩色积木。
- [ ] 候选窄卡片不裁切；无横向溢出；手机候选在下、矮横屏候选在右。
- [ ] 当前面提亮，翻面期间位置关系清楚；合法/非法提示和消除效果不埋入壳体。
- [ ] 主页、设置、结算与纪录面板同属当前视觉体系；运行时无外部美术资产依赖。
- [ ] 正式构建不显示版本，开发构建显示；×2 连击点亮，不遮挡分数。
- [ ] 单线到多线反馈等级可辨，粒子不遮挡下一步判断；检查低性能档与物理手机。
