## 4. 关键实现细节

### 4.1 消除必须扫描全部 6 个面（最重要的一条）

**当前代码**（`board.js` 的 `place()`）：

```js
const lines = this.findFullLines(face)   // ← 只检查放置面
```

**问题**：格子是按立方体**晶格坐标** `(x,y,z)` 存储的（`FACE_LATTICE`），所以**棱上 1 格被 2 个面共享、角上 1 格被 3 个面共享**。在棱/角上落子会同时推进相邻面的进度——只检查放置面，会在别的面留下**已经填满却不会消失的线**。

**现象**：玩家在 `+z` 面落子顺手填满了 `-y` 面某行，转到 `-y` 面会看到一条满线亮着不动，**必须再放一块才结算**。

**改法**：遍历 `FACES` 全检满线，同批结算。

**注意**：`findFullLines(face)` 可以保留签名，改为对每个面调用；被多条线穿过的格子只删一次（现有 `cleared` Set 逻辑正确，可保留）。

### 4.2 几个容易踩的点

- **跨面奖励是加法不是乘法**：2 面 `+200`、3 面 `+600`。不要写成 ×2/×3.5——实测"双面"占全部消除的 31.6%，是基本功，给倍率会放大最常见的操作。
- **面数上限是 3，不要写 4+ 分支**：4 格连通块最多触及 1 个角，一个角属于 3 个面。`CUBE_BURST`（≥4 面）**数学上不可达**，不要实现。
- **线数上限是 12**（不是 5，也不是 10）：倍率表要覆盖到 12，7 线以上是理论区（实测从未出现），表必须在但可以走同一个配置数组。
- **荣誉只发这 5 枚**：`TRIPLE`(≥3线) / `QUAD`(≥4线) / `PENTA`(≥5线) / `HEXA`(≥6线) / `TRIFACE`(3面)。**不要实现** `CROSS`、`DUAL_FACE`、`FACE_WIPE`、`DOUBLE_CROSS`、`SIX-FACE`、`PERFECT_STRIKE`——理由和实测频率见 `08` §5.2。
- **`SIX-FACE`（六面制霸）先不实现**，但**建议把"本局各面是否消除过"的状态先记下来**，因为它是 §2 里最值得抢救的成就，重标后可能直接启用。

### 4.3 显示层仍是旧名

`main.js` 的 `showScorePop(points, lineCount)` 现在只显示两行，需扩展到最多四行：`+分数` / `N LINES` / `M FACES`（跨面时）/ 荣誉名号。

## 6. 验收标准

除 `04-MVP验收清单.md` 全量外，本次新增两条（已在文档中）：

1. **跨面连爆回归项**：一次落子后扫描全部 6 个面结算满线。等价断言——**任意一步落子完成后，6 个面上都不存在残留的已满线**。
   > 这条的反面用例现成：当前代码跑任何一局都可能复现残留，不需要刻意造场景。
2. **首屏 BEST 条款**：允许出现 BEST，但**字号必须小于 SCORE**，不得抢焦点、窄屏不得换行。

另外自测：

- 倍率表 1~12 线的边界值
- 链在"某回合未消除"时正确归零
- 跨面消除的棱/角共享格**只删除一次但每条线都计数**
- 周键跨时区（对齐 CrazyGames 周赛季：周一 09:00 UTC）
- 隐私模式 / `localStorage` 被禁时静默降级，不阻塞开局

## 7. 红线（不要做的事）

1. **主分必须可复现**：不加随机暴击、不加道具分数加成、不做概率触发。CrazyGames 排行榜的分数可信度依赖这一点。
2. **不要硬编阶位数字**（§2）。
3. **不要实现不可达或高频的荣誉**（§4.2），一个永远灰着的徽章不像荣誉，像 bug；一个每局弹 117 次的徽章是噪音。
4. **不要把验证器的结论当成游戏本身**：它是模型，不含道具、不含真实拼块权重、不含 UI 操作成本。频率的绝对值会有偏差，但可达性与量级关系可靠。

### 9.3 与设计的偏离（三条，均已同步回 `08`）

1. **`PERFECT TWELVE` 付分不弹横幅**：`08` §5.1 给它 +20,000 加分，§5.2 又说只进纪录墙、不做徽章播报。两句并存取"加分照付、横幅不弹（`broadcast:false`）"——场上永远只有一个主横幅。
2. **阶位表机制就位、数值留空**：`src/game/tiers.js` 定义 6 档与 P25/P50/P75/P90/P99 口径，`TIER_CUTS` 全为 `null`，`tierForScore()` 返回 `null`，弹层显示"阶位待校准"。**没有写任何假数字**（§2 红线）。定稿难度后可用 `tools/tier-calibration.mjs` 把真实分数样本算出的 cuts 贴进配置即可生效。
3. **验证器同源改造**：`tools/reachability.mjs` 改为直接 `import` 游戏模块，而不是继续手抄模型。改造当场暴露"拼块池还带着 v0.2.31 已移除的 `Line 4`"这一历史漂移（`09` §6）。
