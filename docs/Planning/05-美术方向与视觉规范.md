# VoxalBlast 当前美术规范

> v0.5.0 / 2026-09-14。当前实现依据：rendering/config.js、toyLights.js、main.js、toy.css、ui/icons.js。旧重构提案和历次审查完整保存在 [归档](../Archive/Planning/05-美术方向与视觉规范.md)。

## 1. 视觉方向与资产边界

明亮的塑料积木小游戏：浅冷色背景、实体深蓝六面拼板、高饱和彩色积木、白色厚底控件、海军蓝文字。新游戏为琥珀按钮，续玩为蓝色按钮。

运行时美术由参数化几何、CSS、代码生成内联 SVG、Shader/粒子完成。不依赖外部图片、纹理、视频或预制模型。宣传素材另行制作，不回灌为运行资源。

## 2. 棋盘与空间表达

不透明圆润外壳接收阴影并遮住远面；六面各有 5×5 圆角格槽，当前朝向相机的操作面提亮。占用某晶格后，所有共享面上的对应槽面一起隐藏，避免槽面覆盖方块。

撤销“透明线框笼”“只留底面承托、删除侧面”“内部填充空间”等旧表达。该玩法是六面贴块，不是向容器内堆块。也不要求穿透实体壳展示背面方块。

| 参数 | 当前值 | 入口 |
| --- | --- | --- |
| 背景 CSS | #F4F9FF → #DFECFF → #C2DBFF | toy.css |
| 壳体色 / 粗糙度 | #243C68 / 0.72 | BOARD_STYLE |
| 格槽 / 当前面 | #345785 / #547AB0 | BOARD_STYLE |
| 方块边长 / 倒角 | 0.92 / 0.09 | main.js / BOARD_STYLE |
| 方块粗糙度 / 金属度 | 0.52 / 0 | BOARD_STYLE / makeMaterial |
| 径向抬升 / 曝光 | 0.17 / 1.0 | BOARD_STYLE |
| 反馈沿面法线偏移 | 0.58 | BOARD_STYLE.feedbackSurfaceOffset |

0.17 为从中心向外的径向抬升，不是所有面的法线固定偏移；棱角沿对角方向外移。格槽几何、尺寸和位置仍在 main.js 的 buildFaceTiles，不宣称所有视觉参数已经完全抽入配置。

## 3. 方块与光照

棋盘、候选、拖拽共用圆角方块几何与塑料材质，主页克隆实际棋盘几何。棋盘、候选和主页调用同源 toyLights 灯光，统一 ACES 色调映射与曝光。候选采用固定斜视正交相机，不随棋盘旋转。

阴影已开启：主光投影，壳体/槽面/方块接收阴影。低性能档阴影贴图 1024，高档 2048；档位在初始化时按窗口宽度/硬件并发数选择。主页静态缩影和候选不启用同等阴影链。

不再把旧文“完全没有阴影”当成实现事实。也不宣称已经实现固定顶面 +14% / 侧面 −20% 的手工分面着色、额外 AO 或落地阴影脉冲；当前明暗由统一灯光生成。

## 4. UI 与主页

当前外观以 toy.css 为覆盖入口；styles.css 保留布局与历史兼容规则。旧主页样式已整段替换，其余旧 CSS 尚未全面整理。

主页使用静态、按需渲染的同源 3D 棋盘缩影；不额外添加常驻动画循环。UI 使用厚底、按压位移和清楚的数字层级。四道具、设置、排行榜与键盘入口图标由 ui/icons.js 生成 SVG；部分文本符号仍保留，不以“源码全无 emoji 字符”验收。

设置中文化并采用圆角方形玩具滑块；局内部分文字仍为英文。连击 ×2 起点亮。版本号只在开发构建显示。布局和矮横屏例外见 [03](03-交互与表现需求.md)。

## 5. 动效边界

保留现有分档光束、星星、小方块粒子、镜头震动、得分与荣誉反馈；效果起点沿对应面法线外移，避免被实体壳吞没。等级和数量/时长分别在 honors.js 与 FEEDBACK_STYLE / VFX_CONFIG。

`prefers-reduced-motion: reduce` 时只关闭主页按钮、候选卡与滑块的过渡（toy.css），不改变光效与粒子。粒子批处理依赖 `src/rendering/threeCompat.js` 的 three ⇄ three.quarks 兼容桥：升级 three.quarks 到 0.17.x 后应删除该桥，并重跑 [04](04-MVP验收清单.md) 的停摆回归项，说明见 [技术结构](../Technical/ARCHITECTURE.md)。

候选线呼吸提示、完整“先亮线再收缩消失”流程和独立落子回弹仍不能按旧文认定已交付，见 [待办](../Technical/KNOWN_GAPS.md)。后续修改需写清用途、触发条件、持续时间和性能降级，再做真实尺寸检查。

验收项目见 [04](04-MVP验收清单.md)，已执行记录见 [v0.5.0 验收](../Technical/VISUAL_REFRESH_050.md)。
