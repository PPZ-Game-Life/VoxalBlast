## 0. 方向结论（一句话 + 四条硬规则）

**一座摆在田园草坡上的木质玩具：木头是物体，彩色是唯一的高饱和。**

1. **木材 = 物体**。整块棋盘是 98 个唯一方块；空格为原木，占用格为覆盖木纤维的彩漆。UI 使用暖木边与奶油纸芯，以倒角、光照和下沿厚度表现体积，不靠密集木纹。
2. **彩色 = 内容**。画面上只有「已放置方块」和「落点/道具预览」允许高饱和；其余一律落在木色—奶油纸色区间。
3. **背景 = 布景**。田园风景永远在棋盘之后、永远是柔和低对比的，且**不接收任何指针事件**。
4. **一个方块只有一个尺寸**。`0.94` 边长，块面平整、棱边倒角 `0.085`；邻块间隙 `0.06`。放置不改变块尺寸、高度或位置，棋盘、候选和拖拽沿用同一几何。

## 2. 棋盘 = 98 个唯一方块组成的外壳

**构成模型**：5×5×5 晶格外壳有 `5³ − 3³ = 98` 个唯一格；六面各 25 格合计 150 个表面格，其中棱/角指向同一实体。`buildFaceTiles()` 按 cell 坐标去重创建 98 个 mesh，每个 mesh 的 `userData.faces` 保存其所属面；Three.js 场景树只保留一个父 group。不能为每个面重复创建共面的棱角块，否则会产生重叠、闪烁与不一致的受光。

每块边长 `0.94`、倒角 `0.085`，主体面保持平整，中心在晶格格心，相邻块留 `0.06` 缝隙。最外块面在中心两侧 `±2.47`，读作等大积木拼起的整体。

壳体（`cubeBody`）是背板，用于遮挡穿透视线并提供深色缝底。`hullInset = 0.68` 是**总边长减少量**：背板边长 `5 − 0.68 = 4.32`，相对名义五格外表面单侧缩进 `0.34`，相对实际块面回退 `2.47 − 2.16 = 0.31`，不是单侧缩进 0.68。

统一几何：`blockGeometry = RoundedBoxGeometry(blockSize, blockSize, blockSize, blockSegments, blockRadius)`，**同一个 geometry 实例**给棋盘 98 块、三个候选槽、拖拽幽灵共用，主页缩影也复用场景几何。

| 参数 | 值 | 入口 |
| --- | --- | --- |
| 方块边长 `blockSize` | 0.94（间隙 = 1 − 0.94 = 0.06） | `BOARD_STYLE` |
| 棱边倒角 `blockRadius` / 分段 `blockSegments` | 0.085 / 3（平面宽度约占 82%） | `BOARD_STYLE` |
| 方块位置 | 晶格格心，无任何轴向偏移 | `buildFaceTiles` |
| 背板 `hullInset` | 0.68（总尺寸减少量） | `BOARD_STYLE` |
| 背板尺寸 / 圆角 | 5 − 0.68 = 4.32 / 0.08 | `main.js` |
| 落点预览 `previewLift` | 方块外表面再外移 0.03 | `BOARD_STYLE` |

**放置一个方块 = 把那一格的材质从「原木」换成「漆」。** 不新增网格、不改尺寸、不改位置、不改朝向、不改高度。棱格/角格本来就是一个 mesh，自然形成相邻面同色的包角；当前面提亮检查 `faces.includes(front)`，不会因该 mesh 挂在哪个 group 而漏掉共享格。

> 背板保留小圆角 `0.08`；几何调整后应检查八角和斜视缝隙，不用明亮背板伪装缝底。

### 2.1 演进记录

| 版本 | 模型 | 为什么错 |
| --- | --- | --- |
| v0.5 / v0.7.0 | 已放置方块 = 独立凸出 0.30 的 chip | 棱/角格必须挑一个面出手 → 正面下沿的角格同时在底面长出一片，方块从立方体底部挂出来 |
| v0.7.1 | 面片贴壳、几乎齐平（厚 0.10） | 几何把圆角钳到 0.05，读作"平贴纸片"；且壳体比面片浅，缝隙是浅色勾缝 |
| v0.7.2 | 面片整体抬高 0.13、加厚 0.30 | 变成了绗缝软垫：整个立方体像垫子，不是"平的方块拼起来" |
| v0.7.3–v0.7.4 | 150 个按面创建的 0.91³ 立方体 + 0.09 缝隙 | 棱角同一格重复创建；真实外壳只有 98 个唯一实体 |
| **v0.8.0–v0.8.5（现行模型）** | **98 个唯一 0.94³ 立方体 + 0.06 缝隙** | 按晶格去重；v0.8.5 增加云纹、粗糙度变化与接触 AO，倒角调为 0.085 |

关键教训：**`RoundedBoxGeometry` 的圆角半径会被钳到"最短边的一半"以内**。用薄片当方块时圆角必然被吃掉，所以"方块"必须是真正的立方体，而不是薄片加抬升。

## 4. 材质与光照

`blockSurfaceMaps(painted, variant)` 为原木和彩漆各缓存三组 256×256 纹理：域扭曲云纹叠加较细笔触，原木另有低对比生长轮廓，彩漆覆盖木纤维。色彩图 `map` 使用 sRGB；独立高度图 `bumpMap` 与 `roughnessMap` 保持数据色彩空间。纹理不烘焙方向高光，色彩图在 UV 边界收敛以减轻接缝；背板仍用 `woodGrainTextureRepeating(2.2)`，UI 使用自己的确定性 CSS 木纹。

`toneIndexFor()` 以晶格坐标确定原木六档色调与纹理变体，避免相邻块完全重复。棋盘、候选、拖拽沿用同一套几何与材质生成入口。

| 材质参数 | 原木方块 | 彩漆方块 | 背板 |
| --- | --- | --- | --- |
| 材质类型 | `MeshPhysicalMaterial` | `MeshPhysicalMaterial` | `MeshPhysicalMaterial` |
| `roughness` | 0.46 | 0.31 | 0.7 |
| `clearcoat` / `clearcoatRoughness` | 0.38 / 0.3 | 0.85 / 0.17 | 0.1 / 0.42 |
| `bumpScale` | 0.022 | 0.011 | 无凹凸图 |

`roughnessMap` 调制基础粗糙度，使块面反光有轻微变化；不把整面做成镜面。`toyLights.js` 的半球光为天空 `#FFF4DF`、地面 `#A49A7B`、强度 0.65；主光 `#FFEFD6`、强度 2.4、位置 `[-3.5, 7, 5]`；补光 `#C9E3FF`、强度 0.5、位置 `[5, 2, -4]`；轮廓光 `#FFE6C4`、强度 0.75、位置 `[-4, 4, -5]`。

共享环境为 256×128 线性 HDR HalfFloat 纹理，各 renderer 独立 PMREM 过滤；`environmentIntensity = 0.7`。反射主光箱的强度/集中指数为 `12 / 48`，轮廓光箱为 `4 / 32`，方向分别跟随主光与轮廓光。主画布在 HalfFloat composer 的末端执行一次 ACES；候选与主页由 renderer 执行 ACES，曝光统一为 1。

主光阴影使用 PCFSoftShadowMap，低性能档 1024、高档 2048。主棋盘另有暖褐 `#60422E` 接触 SSAO：`radius 0.075 / intensity 1.65 / bias 0.012 / fade 0.018`，世界接近阈值/衰减 `0.35 / 0.45`，亮度影响 0.15。桌面采样/圈数/分辨率比例为 `16 / 3 / 0.75`，移动或低性能档为 `11 / 3 / 0.5`。

AO 使用独立 `NormalPass` 生成的法线和真实深度，避免 composer 深度附件自拷贝；具体链路与 resize 顺序见 [技术结构](../Technical/ARCHITECTURE.md)。禁用玻璃、霓虹、随机高光、逐块不同光向及过量辉光。

## 5. 背景（田园布景）

`installPastoralBackdrop(#app)` 在启动时把 `.pastoral-backdrop` 插为 `#app` 的第一个子元素。

> ⚠️ **绘制顺序陷阱（本版踩过）**：`z-index:-1` 的层画在根层叠上下文的第 2 步，而 **`body` 自己的背景画在第 3 步——在它之上**。所以天空渐变必须挂在 `html`（传播到画布，最底层），`body` 必须是 `transparent`，否则整张田园风景会被一层纯色渐变静默盖住。`src/toy.css` 末尾的「Backdrop paint order」段即为此。

- 层序（后→前）：天空渐变 → 太阳辉光 → 云 → 远山 → 中景丘陵 → 村庄（含教堂尖顶） → 河流与石桥 → 树线 → 草坡 → 木栅栏 → 左上角大树 → 草簇与雏菊 → 地平线雾气 + 暗角。
- 取景：`viewBox 1440×1000` + `xMidYMid slice`。桌面裁上下、手机取中间约 35% 宽度——**因此草地、丘陵、河流必须横向通铺**，村庄居中而非塞在角落。
- 交互：`pointer-events: none` + `aria-hidden`，永不接收事件、不可聚焦。
- 对比度约束：布景整体低对比，画面最亮最饱和的永远是立方体。

## 7. 反 AI 制作约束

1. 先写清用途/尺寸/状态/明暗方向，再谈表现。
2. 用可复用基础几何 + 明确比例，同类资产只做少量有意变体。
3. 光源、透视、圆角半径、线宽、阴影软硬度全项目统一；发现多套光照优先返工。
4. 禁随机细节填充：随机划痕、随机高光/装饰/渐变、无意义字母、乱码。
5. 生成式素材只能当草稿，须重建为可编辑的矢量/CSS/Shader/低复杂度模型并人工检查。
6. UI 文案、图标、数值一律用明确设计稿。
7. 新资产过「缩小到实际游戏尺寸」和「灰度模式」两道检查。
8. **一切「体积」必须能写成一个数**（见 §0.4）。
