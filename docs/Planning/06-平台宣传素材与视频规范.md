# VoxalBlast 宣传制作说明

> 对应游戏 v0.7.0。制作建议，不代表平台已收件或素材已交付。（v0.7.0：美术方向改为木质田园，规则与数值未变）

## 1. 画面来源

从 npm run build + npm run preview 的正式构建录制，确保没有开发版本号。展示实体六面拼板、固定候选拖放、翻面、单线/跨面连爆与真实结算。不要使用旧透明笼、容器内填块或未实现商店/全球排行画面。

截图与视频必须可由当前游戏复现；允许裁切、标题和字幕后期，不能编造奖励或玩法。运行时素材边界见 [05](05-美术方向与视觉规范.md)。

## 2. 制作建议与平台确认

**2026-09-17 更正**：本节的旧建议（"20～30 秒横版""1200×1800 / 1600×1600 工作尺寸"）与 CrazyGames 现行官方规格不符。官方硬规格已核并写入 [上线物料包](上线物料包.md)：封面必须三张横 16:9 1920×1080 / 竖 2:3 800×1200 / 方 1:1 800×800，预览视频 15～20 秒、≤50MB、无声、**横版与竖版各一支**（均 1080p）、首帧用静态封面。以 [上线物料包](上线物料包.md) 为准，本节仅保留镜头与内容口径。

视频可保留 1080p/30fps 母版。上传前仍由发布人员在后台复核当前字段要求；[上线物料包](上线物料包.md) 里的数字取自官方文档，平台改规则时两处同步更新。

## 3. 交付检查

- [ ] 缩略图能认出六面棋盘和可操作拼块。
- [ ] 每种比例独立构图，避开边缘及 UI 遮挡。
- [ ] 至少展示真实放置、旋转和一次消除，主卖点突出跨面关系。
- [ ] 无调试信息、浏览器外框、伪图标、乱码或不存在的功能。
- [ ] 导出记录游戏提交、素材版本、日期与实际平台字段要求。

仓库尚未据此确认宣传素材包完成。历史分镜和目录建议见 [归档原稿](../Archive/Planning/06-平台宣传素材与视频规范.md)。
