# VoxalBlast 平台宣传素材与视频规范

> 版本：MVP v0.2
> 负责人：美术总监
> 适用平台：CrazyGames Developer Portal 及后续网页游戏平台

## 1. 责任范围

平台发布所需的宣传图、商店展示图、缩略图、宣传视频和对应的裁切适配由美术统一负责。程序需要提供稳定、无调试信息的可录制版本；策划需要提供最终卖点、玩法顺序和文案；美术负责视觉脚本、构图、录制指导、后期、导出和版本归档。

所有宣传素材必须展示真实可玩的 VoxalBlast，不使用与实际玩法不一致的伪场景、夸张 UI 或无法复现的效果。

运行时视觉资产遵循《05-美术方向与视觉规范》的全量程序化要求，不把宣传 PNG/JPG、PSD、视频或外部模型带入游戏包。营销源文件与导出文件只用于平台提交和人工排版后期，必须以真实运行画面为底稿。

## 2. CrazyGames 素材规格基线

根据 Developer Portal 当前 Art 页面截图，首批准备以下三种 Marketing creative：

| 素材 | 比例 | 推荐工作尺寸 | 用途 |
| --- | ---: | ---: | --- |
| 横版主宣传图 | 16:9 | 1920×1080 | 桌面端主展示、列表和推广位 |
| 竖版宣传图 | 2:3 | 1200×1800 | 移动端/竖版展示位 |
| 方版宣传图 | 1:1 | 1600×1600 | 卡片、推荐位和社交分享 |

工作文件保留至少 2 倍于平台显示尺寸的源文件或可编辑工程；上传前按平台要求导出 PNG/JPG。最终尺寸以 Developer Portal 当前字段提示为准，平台要求变化时以最新后台和官方文档为准。

宣传视频准备横版主版本，建议导出 `1920×1080`、`30fps`、H.264 MP4，并保留无字幕母版和带字幕版本。若后台要求不同编码或大小，使用母版重新导出，不对压缩文件反复转码。

Marketing creatives 若采用 URL 提交，URL 必须是稳定、公开可访问、无需登录和不会过期的地址。每次提交记录素材版本、上传日期和对应游戏版本。

## 3. 主宣传图构图

### 横版 16:9

- 棋盘和正在形成的多线消除作为第一视觉主体，占画面约 45%～60%。
- 左侧或上方保留游戏名 `VoxalBlast` 和一句短卖点，避免压住棋盘关键格子。
- 展示 3D 棋盘的层次、可旋转性和颜色关系，不使用纯二维平铺截图作为主画面。
- 画面边缘预留约 8% 安全区，标题、Logo 和关键方块不得贴边。
- 重点展示“差一格完成直线”或“多线同时消除”，让玩家不看说明也能理解目标。

### 竖版 2:3

- 棋盘居中偏上，保证缩小为手机卡片后仍能看清 5×5×5 结构。
- 游戏名置于顶部安全区，当前方块和得分可放在下方，但不能堆叠过多 UI。
- 竖版不得简单裁切横版；重新安排棋盘、标题和消除爆点的比例。
- 重要信息集中在中轴区域，避免左右边缘出现孤立小字。

### 方版 1:1

- 使用单一强动作：一个方块即将补齐直线，或一组线正在消除。
- 标题最多一行，字数保持短；不塞入玩法说明、操作说明和多组数据。
- 棋盘轮廓和主色块必须在小尺寸缩略图中仍然可识别。

## 4. 宣传图视觉规则

- 延续《05-美术方向与视觉规范》中的梦幻天蓝背景、深海军蓝棋盘、高饱和彩色积木、统一光源和柔和阴影。
- 宣传图可以比游戏内画面更聚焦、更有冲击力，但材质、色板、方块形状和光照不能换成另一套风格。
- 允许使用一次明确的消除高光或粒子爆点；禁止满屏光晕、烟雾、火焰、随机碎片和无法解释的魔法特效。
- 文案使用人工校对的短句，不让生成工具直接决定 Logo、品牌字样或玩法文字。
- 禁止伪造排行榜、虚构功能、夸大“无限关卡”等实际未实现内容。
- 禁止使用竞品 Logo、截图、角色、商标或近似品牌构图。
- 所有宣传图必须经过桌面大图、移动缩略图和灰度三次检查：主体清楚、文字不溢出、颜色不是唯一识别手段。

## 5. 首批宣传图内容方案

### 方案 A：主视觉「三轴连爆」

展示 5×5×5 棋盘中一枚彩色立体方块完成 x、y、z 三个方向的交叉线，三条线以不同颜色高亮并开始消除。标题使用 `VoxalBlast`，副文案建议为 `Build the line. Blast the cube.`。副文案只作为暂定文案，最终以平台语言版本为准。

### 方案 B：玩法「Rotate. Place. Clear.」

左侧展示可旋转的候选方块，中央展示半透明合法预览，右侧展示完成消除后的棋盘。三个状态必须来自同一套游戏素材和光照，不制作无法在游戏中复现的“前后对比”。

### 方案 C：小图「差一格」

特写一条只差一格的直线，待放方块与空缺位置之间用清晰的预览轮廓连接。此图作为方版或社交分享图，不承担完整玩法说明。

## 6. 宣传视频结构

首支视频建议控制在 20～30 秒，前 3 秒必须出现棋盘和动作，不使用 Logo 长片头。

| 时间 | 内容 | 画面要求 |
| --- | --- | --- |
| 0～3s | 棋盘与差一格状态 | 立即看懂目标，镜头稳定 |
| 3～8s | 旋转方块并拖拽预览 | 清楚展示合法吸附和 3D 视角 |
| 8～14s | 放置并完成一条线 | 先固定，再高亮，再消除 |
| 14～20s | 多线连爆 | 反馈增强但不能遮挡棋盘 |
| 20～25s | 分数跳升与新方块 | 展示持续决策，不停留在结果画面 |
| 25～30s | Logo 与短 CTA | `Play VoxalBlast`，保留品牌安全区 |

视频制作要求：

- 使用干净录制环境，隐藏浏览器地址栏、开发者工具、调试网格、鼠标异常轨迹和性能面板。
- 镜头以真实游戏操作为主，可做轻微裁切和慢放，但不能改变落点、速度或规则结果。
- 鼠标轨迹只在需要解释拖拽时出现，使用高对比但低干扰的圆点或细线。
- 单线消除和多线消除各至少出现一次；多线反馈必须明显更强。
- 音效采用放置、消除、连爆三类短促声音；同时交付无音频版本，方便平台和地区适配。
- 字幕和 Logo 交付可关闭的独立图层版本；视频内文字避免贴边和过小。
- 首尾各保留至少 12 帧稳定画面，便于平台转码和截帧。

## 8. 发布前验收清单

- [ ] 已准备 `16:9`、`2:3`、`1:1` 三种宣传图。
- [ ] 每种比例都经过独立构图，不是粗暴裁切。
- [ ] 缩略图中可识别棋盘、彩色方块和一次明确的消除动作。
- [ ] 宣传图没有乱码、伪 Logo、竞品素材或未实现功能。
- [ ] 横版视频完成 20～30 秒主版本，并交付无字幕/带字幕/无音频版本。
- [ ] 视频展示旋转、预览、放置、单线消除和多线消除。
- [ ] 视频录制无调试信息、浏览器界面和异常鼠标轨迹。
- [ ] 所有导出文件可正常打开，尺寸、比例、帧率和编码符合后台提示。
- [ ] URL 提交素材可公开访问且不会过期。
- [ ] 素材版本与提交的游戏版本已记录。
