# VoxalBlast 道具系统设计

> 版本：v0.1（MVP 后首个扩展，规划基线）
> 项目：VoxalBlast
> 平台：CrazyGames Web 端
> 文档状态：评审稿
> 依赖：`01-立项PRD.md` / `02-核心规则与数值.md` / `03-交互与表现需求.md`

## 0. 文档定位

本设计把 Block Blast 类游戏最通用的**四件套道具**（换批、锤子、火箭、炸弹）做一次三维化适配，作为 MVP 之后的第一个内容扩展。

- MVP 明确不含道具（见 PRD 第 5 节「明确不包含」），本设计**不改变 MVP 核心规则**。
- 四个道具全部定位为**空间治理型**：清格子、换手牌，**不直接得分、不推进回合**，从根上避免道具成为刷分工具，保住对局结果与积分的可信度。
- 设计目标是让道具成为「死局前的最后一口气」和「差一格手痒时的精准救场」，而不是无限续命。

## 1. 设计原则

1. **不直接计分**：得分只来自「落子触发消除」。道具清理棋盘后，玩家靠后续放置自然得分。
2. **不动回合节奏**：使用道具不消耗当前候选、不推进回合、不触发 Game Over 判定；结束即回到原回合。
3. **数量受限**：每局每种道具有固定初始配额，用完即止，杜绝「道具刷到天荒地老」。
4. **先救局、后锦上添花**：收益随棋盘拥挤度自然放大——清得越多越救命，但开局滥用收益低，玩家会自己判断时机。
5. **与已定稿状态机兼容**：取消/非法放置不耗块不计分不退回合的规则不变；道具使用与拖拽/旋转操作互斥。
6. **对齐视觉基调**：道具反馈沿用亮黄高光、线色小方块与星星的程序化语言，不做火焰/烟雾类解释不通的特效。

## 2. 四道具总览

| 道具 | 定位 | 作用 | 强度 | 图标建议 |
| --- | --- | --- | --- | --- |
| 🔄 换批 | 供给救济 | 当前 3 个候选方块整体重抽 | 不动棋盘 | 旋转箭头 / 洗牌符号 |
| 🔨 锤子 | 精确点杀 | 敲掉棋盘上 1 个已占用单元 | 1 格 | 卡通锤 |
| 🚀 火箭 | 直线切割 | 清除当前面上的整行或整列(长度 5) | 1 条线 | 指向轴线的火箭 |
| 💣 炸弹 | 范围爆破 | 清除选中格所属 2×2 区域内全部方块 | 最多 4 格 | 圆滚滚炸弹 |

强度递增排序：换批(0) < 锤子(1) < 火箭(1 线) < 炸弹(≤4 格)。
六面体是 **5×5×5 立方体的外壳**，共 **98 格**——不是 6×25=150，因为棱上的 1 格被 2 个面共享、角上的 1 格被 3 个面共享（见 `src/game/board.js` 的晶格存储）。可消线共 **60 条**（6 面 × 每面 5 行 + 5 列）。炸弹封顶 4 格约占 4%，视觉上「解围但不洗盘」。

## 3. 道具详情

### 3.1 换批（Refresh）

- **效果**：把当前供给区 3 个候选方块整体丢弃并重抽 3 个新方块。
- **规则**
  - 不改变棋盘，不消耗任何方块库存以外的资源。
  - 重抽结果允许与旧手牌部分重合，但不允许三者与旧手牌完全同序同形（避免「白用」）。
  - 换批后若新 3 块仍全部无合法位置 → 正常进入 Game Over（不额外豁免）。
- **用途**：手牌形状与棋盘不搭时主动止损；Game Over 判定时是最后的喘息机会（见 §7）。
- **手感目标**：它是四个道具里玩家最先用、用得最多的「安全网」。

### 3.2 锤子（Hammer）

- **效果**：点选棋盘上任意一个**已占用单元**，将其移除。
- **规则**
  - 一次只能敲 1 个单元；目标格为空时不可选中。
  - 敲掉的是组成某形状的其中一个单元时，其余单元原样保留（拼块无重力，允许悬空残留）。
  - 若被敲单元与其它块恰好不再构成完整线，属正常结果；锤子**不会触发消除或计分**。
- **用途**：拆掉堵住「差 1 格候选线」的单块；清理被自己放歪的形状，腾出关键槽位。
- **手感目标**：最强确定性，给「只差一块」的懊恼时刻一个温柔的后悔药；单格效果保证它再强也只是一格之遥。

### 3.3 火箭（Rocket）

- **效果**：点选当前朝向前方的面上任意位置，清除该面的**整行或整列**（长度 5）上所有已占用单元；行/列方向可切换（Row/Col 按钮或 R/C 键）。
- **交互**：点选前面上任意位置，默认清除该位置所在方向（程序先选行，可切换列）；点选前用 Row/Col 切换方向。
- **规则**
  - 若所选行/列上没有任何块，不可触发。
  - 清除后不结算、不计分（即使该线此前已满格也不会给分——它是一次「拆迁」，不是「消除」）。
- **用途**：整线移除效率高，是死局堆积最严重时的主力解围手段；也用于拆掉「整条就差你这块」的干扰长条。
- **手感目标**：呼应六面体「每面行列成线」的核心语义——道具与玩法语言同构，学一次就会。

### 3.4 炸弹（Bomb）

- **效果**：点选当前朝向前方的面上任意一个**已占用单元**作为锚点，清除以锚点为顶角的 **2×2** 方块区域内的全部方块（最多 4 格）。
- **规则**
  - 锚点格必须已占用；选格后 2×2 区域以**向坐标正方向延伸**为准（u/v 各取 +1），保证六面体(每面 5×5) 内任意锚点都有确定的作用域，越界处自动裁剪。
  - 区域内仅清除已占用单元，空格跳过。
  - 不结算、不计分。
- **用途**：一次拔掉一片碍事积木，适合「三个候选全被地形卡死、敲一锤子不够」的危机局面。
- **手感目标**：四件套里单次威力最大、最该省着用；用对时机能瞬间打开一整片放置空间。

## 4. 获取与配额

> MVP 后先做「局内有限配额」，暂不引入金币/商店（遵守 03 文档：手机版不加入金币与商店体系）。

| 渠道 | 规则 |
| --- | --- |
| 开局免费 | 每局初始：换批 ×2、锤子 ×1、火箭 ×1、炸弹 ×1 |
| 奖励广告 | CrazyGames 激励广告位（Rewarded Ad）：看广告可将**指定道具**在本局持有数 +1；换批单局最多补到 3，其余道具单局最多补到 2 |
| 局内掉落 | 暂不做（避免经济复杂度），记录为开放选项 |

- 每局各道具**持有上限**：换批 3 / 锤子 2 / 火箭 2 / 炸弹 2。
- 本局没用完的道具**不跨局保留**（无背包、无仓库），保持单局制纯净。
- 广告相关时机、暂停、回调约束复用 PRD §8 与 03 文档既有条款：广告展示时暂停并停用输入，恢复后不得重复计数或重复发放。

## 5. 使用时机与状态机衔接

道具使用属于**回合外动作**，只在「非拖拽、非旋转、非结算播放」的空闲态可用：

1. 空闲态 → 点道具图标 → 进入对应选择态（换批无选择态，直接生效）。
2. 选择态下：可取消（Esc / 右键 / 拖回取消区等价入口），取消**不消耗道具**。
3. 确认生效 → 播放反馈 → 回到空闲态，**当前 3 候选与回合序号保持不变**，可继续正常放置。
4. 道具使用不会改变「取消不耗块不计分不退回合」的任何语义。

互斥清单：

- 拖拽方块进行中：道具禁用。
- 旋转动画播放中：道具禁用。
- 消除/计分反馈播放中：道具禁用。
- Game Over 面板弹出后：局内道具不可用（复活机制不在本次范围）。

## 6. 操作与布局

### PC（横屏三栏）

- 道具图标排布在**右侧候选区上方**的一行，四个图标一次排开，与候选方块共用右侧纵向栏；图标上显示本局剩余数量（换批 ×2 等角标）。
- 悬停显示一行效果文案；点击后进入选择态，棋盘上出现预览高亮（锤子=目标格、火箭=目标线、炸弹=2×2 区域），再次悬停/点击切换目标，左键确认，右键/Esc 取消。

### 手机（竖屏）

- 四个道具图标放在**候选方块上方**一行（横向 4 个），避开底部触摸操作区与系统安全区。
- 进入选择态后，点击棋盘目标格确认；用底部已有的旋转/视角控制不足以精确换轴时，火箭选择态提供 x/y/z 三个切换按钮浮层。
- 数量角标字号不小于 10px，保证可读；不可用（数量 0 或互斥态）时置灰。

### 选择态预览

- 复用「合法/非法」语义：道具目标一律高亮为可执行态；无块可清的目标不可点击。
- 反馈顺序：目标高亮 → 执行动画（沿作用轴/区域收缩淡出）→ 遗留空格短暂呼吸提示可放置位置，全程 ≤ 500ms，不遮挡后续落点判断。

## 7. Game Over 与道具的边界

- 当 3 候选全部无合法位置：先判定为「预备 Game Over」。
- 若玩家仍有**换批**：弹出轻量提示「换一批试试？」（非强制弹窗，点击即换，也可直接关闭进入 Game Over），此窗口不计入回合。
- 换批后仍全死 → 正式 Game Over；锤子/火箭/炸弹**不参与**复活判定（它们不能凭空造出手牌位置，且避免「拿道具无限续命」）。
- Game Over 面板后可展示「本局道具使用统计」作为轻量化复盘（可选）。

## 8. 数值与手感目标

| 指标 | 目标 |
| --- | --- |
| 道具平均使用次数/局 | 换批 0.8～1.5，锤子 0.5～1，火箭 0.3～0.8，炸弹 0.2～0.6 |
| 道具导致的反超局比例 | 用道具后成功续命并多撑 ≥5 步的对局占比约 30%～50% |
| 「差 1 格」时刻道具响应 | 玩家在差 1 格状态用锤子的决策时间应 < 2 秒（UI 可达） |
| 对局时长影响 | 平均单局时长 +20%～40%（MVP 2~5 分钟 → 道具局 2.5~7 分钟），不得突破 8 分钟 |
| 死局解脱成功率 | 持有至少 1 个换批时，预备 Game Over → 成功续命的概率 ≥ 70% |

以上数值为手感基线，进入 D1/D2 实测后允许整体缩放；若「广告换道具」拉高付费深度，再单独校准配额。

## 9. 视觉与表现需求

- 道具图标：全程序化生成（代码几何 + 圆角造型），风格与现有 UI 图标同源，不用外部贴图；手机上仍清晰可辨。
- 锤子执行：目标格「敲击 + 碎成 2~3 个小方块」沿原轴散落消失。
- 火箭执行：火箭从屏幕边缘沿目标轴线飞入贯穿，整线收缩淡出；高亮沿用线色。
- 炸弹执行：2×2 区域以锚点为起点做小范围闪光膨胀，被清方块转亮黄后碎裂；粒子数量与爆炸语义匹配，不越过消除反馈的强度上限。
- 换批执行：候选区三块依次淡出、新三块依次飞入，不加粒子。
- 与 MVP 一致：禁止白色过曝、全屏泛白、火焰烟雾与无法解释的魔法特效；低性能档降级为「缩小粒子量 + 保留轴向信息」。

## 10. MVP 之外范围声明

本系统的所有内容均属于 **MVP 之后（D1/D2）** 的扩展项：

- 不属于 MVP「必须包含」，不进入 `04-MVP验收清单.md`。
- 上线首版若资源紧张，建议优先级：换批 > 锤子 > 火箭 > 炸弹（投入产出比递减且换批天然承接广告位）。
- 需要回写本文件或相关文档时，遵循 `docs/Planning` 修订流程（在本文件内维护修订记录，不覆盖已定稿 MVP 章节）。

## 11. 开放问题

1. 炸弹作用域定为 2×2 是否最优？备选：以锚点为球心的曼哈顿半径 1（六面体(每面 5×5) 内最多 7 格），实测后择优。
2. 火箭 A/B 两种交互（默认轴 vs 三轴按钮）先保 A 版进原型，若点选歧义大再切 B。
3. 局内掉落与「每日免费道具」是否纳入第一版上线内容，取决于变现节奏，本次不承诺。
