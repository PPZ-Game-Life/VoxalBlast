# VoxalBlast 核心规则与数值

> 版本：MVP v0.2

## 1. 棋盘模型

- 棋盘为 `4×4×4`，坐标范围为 `x=0..3`、`y=0..3`、`z=0..3`。
- 一个格子最多容纳一个方块单元。
- 方块由若干个单位立方体组成，整体放置，不允许穿过已占用格或棋盘边界。
- 放置完成后立即写入棋盘并保持静止。

## 2. 消除判定

每次放置结束后，分别检查三类方向：

- x 线：固定 y、z，x 从 0 到 3 全部占用。
- y 线：固定 x、z，y 从 0 到 3 全部占用。
- z 线：固定 x、y，z 从 0 到 3 全部占用。

所有满足条件的线在同一结算批次中消除。被多条线共同穿过的格子只删除一次，但每条完整线都计入本次消除数量。

## 3. 计分

基础分建议如下，实际手感测试时允许整体缩放：

| 同次落子消除线数 | 倍率 | 基础得分 |
| --- | ---: | ---: |
| 1 | ×1 | 100 |
| 2 | ×3 | 300 |
| 3 | ×6 | 600 |
| 4 及以上 | ×10 | 1000 起 |

建议公式：`本次得分 = 100 × 消除线数 × 对应倍率`。  
若同一次落子穿过多条线，优先展示“消除线数”，再展示倍率和累计分数。首版不做爆炸式多阶段连锁，专注于一次落子多线消除。

## 4. 方块池

首版约 8 类形状，优先覆盖以下结构：

- 直线：长度 3、4。
- 平面 L 形。
- 平面田字形。
- 立体 L 形。
- 立体角块或小型立方块。
- 由二维经典形状沿 z 轴延伸的变体。

形状生成原则：

- 前期保证存在可放置位置，避免随机开局即死。
- 中后期提高填补缺口的机会，让玩家频繁遇到差 1～2 格成线。
- 不要求每一回合都能消除，保留空间规划压力。

## 5. 供给与 Game Over

- 每回合展示 3 个方块。
- 当前方块可旋转后再尝试放置。
- 当三个方块都不存在任何合法放置姿态时，触发 Game Over。
- Game Over 面板显示最终分数、最高分（若有）和重新开始按钮。

## 6. 目标手感

- 开局节奏宽松，让玩家理解三维棋盘。
- 中后期平均每 2～3 步出现一次差 1～2 格的候选线。
- 玩家应能通过观察和旋转解决大部分局面，而不是依赖随机运气。
- 允许出现无解局，但无解应来自空间管理失误或可理解的供给结果。
