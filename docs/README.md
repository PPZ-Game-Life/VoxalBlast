## 目录职责

- **Planning/**：当前实现与产品约定。沿用 01～08 文件名，便于已有引用继续查找。
- **Technical/**：技术入口、部署事实、已知缺口和具名版本的验证记录。
- **Archive/**：整理前原稿、历次修订原因、历史模拟数据和已完成交接单。这里的“必须”“禁止”“待实施”只代表当时决策，不覆盖现行文档。

[历史资料索引](Archive/README.md) 包含原 09 验证报告、10 开发交接单。源码注释中遗留的旧章节编号可到对应归档原稿追溯。

## 维护约定

1. 当前行为由对应代码核实；提案不得写成已实现。
2. 修改行为时同步相应现行文档；历史推导放 Archive，不再往现行正文追加多代版本说明。
3. 回归清单的空框表示待执行项目，不等于当前存在缺陷；通过记录必须写明版本、环境与验证范围。
4. 平台能力、远端部署状态、物理手机表现不能仅凭本地构建成功认定。已知边界集中维护在 KNOWN_GAPS。
5. 若再改美术，先更新 05 中的当前裁决，再实现、验证；代码协作按当次任务授权执行，不沿用旧稿的人名职责禁令。
