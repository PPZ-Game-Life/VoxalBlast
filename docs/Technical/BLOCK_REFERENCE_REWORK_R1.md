## 3. 1:1 目视结论（`assets/block-reference-review/`）

同尺寸同位置裁切，R0 与 R1 可直接对照：

| | before（R0） | after（R1c） |
| --- | --- | --- |
| 单块 1:1（147px = 3 格） | `before-r0-block-1to1-color.png` | `r1-block-1to1-after.png` |
| 候选 1:1（366×117） | `before-r0-candidates-1to1-color.png` | `r1-candidates-1to1-after.png` |
| 彩色盘面手机全屏 | `before-r0-color-mobile.png` | `r1-color-mobile-after.png` |

- **果冻感消除。** before 的彩块面内有显著的中心／薄边变化、上沿近乎全白的硬边，
  读作琉璃按钮；after 的面是**平整饱和 + 一条柔和宽高光**，与参考同向。
- **两段式分界消失。** before 单个面被切成亮带 + 暗带（§3 P1「颜色被分成内外两层」）；
  after 基本均匀，只剩一层很弱的左亮右暗，来自环境反射卡。
- **面仍亮、仍有光泽**，不是哑光色纸 —— 与参考的「实心亮面玩具」一致。
- **候选与棋盘同源同步变化**，没有出现「候选突然换材质」。

## 4. 与参考图仍然存在的差距（**不是 R1 的欠账**）

1. **候选看不见厚度。** 参考的每个候选立方体露出顶面（约块高 20%），我们只有一条 2–3px 亮边。
   → 属 §5.1「轻微展示厚度」，是**候选预览相机**的姿态问题，归 **R3**，不是材质。
2. **棋盘上没有逐块可见的顶面。** 参考的实心感有很大一部分来自三面构图（每块露出顶面）。
   → 属 §7 **方案 B**，明确不在默认范围；R1 无法补回这部分几何信息。
3. **木块仍偏暖棕、鼓面更明显。** 参考是接近 `#F0DEC0` 的浅奶油、面内近平。
   → §4.2 把木块排在彩块之后（`woodCrownHeight` 0.012 → 试 0.004～0.008），**本轮未动**，
   留作 R1 后续或 R2，等 Luna 对彩块方向点头再动。
4. **块缝仍偏宽、偏暖棕。** 参考的缝更细、更少棕色。→ §4.2 排在材质之后，本轮未动。
5. **候选 ÷ 棋盘 的尺度比**（实测 47–48% vs 参考 59–65%）→ 属布局／立方体尺度，按制作人
   指示**本轮不动**，见 R0 §9bis.2。
