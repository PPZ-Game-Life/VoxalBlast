# 现行 14 类候选池的难度曲线（v0.8.15 实测）

> v0.8.15 / 2026-09-20。**纯测量**：只动 `tools/`（新增两个 Block 9 归因臂）与技术文档，玩法、发牌权重、渲染、存档、版本号一律未改。模拟直接 import 规则层（board / shapes / `SHAPE_WEIGHTS` / 开局预置），5×5×5 外壳、98 个唯一格、每批三候选、**无道具**、上限 600 步。
> 原始结果（入库）：[池 14 类主表](../../tools/results/difficulty-pool14-curve.html)、[熟练打法](../../tools/results/difficulty-pool14-curve-space.html)、[Block 9 归因](../../tools/results/difficulty-block9-sweep.html)，同名 `.summary.json` 存聚合值；逐局记录与完整曲线只在本地全量 JSON 里（不入库）。上一轮的紧张度基线见 [紧张度测量](DIFFICULTY_TENSION.md)（十类池），本文是它的现行池续篇。

## 1. 结论

1. **现行池第一次让"会消除的玩家"也会死。** 贪心打法（每步取最大消除）自然结束率 **92.5%**、中位 206 步；典型打法（noise，75% 贪心 + 25% 随机）**99.7%**、中位 **92 步**；纯乱放 **100%**、中位 **23 步**。v0.8.4 之前的十类池里，同一套模拟下贪心是 **0%**、noise 是 **1.0%**（都在 600 步内不死）。
2. **但曲线不是"越玩越紧"，而是"长期平坦 + 一次致命"。** 12 步分桶里，占用率在前约 100 步爬到 25～30 格（98 格的 1/4～1/3）之后**几乎不再变化**：贪心此后 300 多步一直停在 ~25 格、每步可选落点 ~125～140、"极紧步"（mobility ≤ 8）只占 **1～2%**、消除步稳定在 **~71%**。死亡不是被慢慢挤死，而是某一手里的大件（3×3 / 3×2）再也放不下。
3. **死法不是"发牌即死"**：贪心与 noise 的 `gamesEndingOnFreshDeal` 都是 **0%**、`freshDealStuck` ≈ 0%——都是在同一手内先用掉小件、把大件留到最后才卡住。这条对道具设计有意义：**换批（refresh）正好能救这一手**，而模拟里没有道具。
4. **归因清楚：这个陡变基本由 Block 9（3×3，占发牌槽位 4.8～5.0%）造成。** 权重 1 → 0.4 → 0（删掉）→ 十类池，贪心的结束率是 **92.5% → 69.5% → 1.7% → 0%**，noise 是 **99.7% → 95.3% → 15.8% → 1.0%**。也就是说 13 类池（Rect 6 / L 5 / 斜三格）只把 noise 从 1.0% 抬到 15.8%，**剩下那一大截是 Block 9 一个人干的**。
5. **熟练打法（一步前瞻 `space`）仍然 0% 结束**，但它的"一局最紧时刻"从十类池的 **66** 个落点掉到 **22** 个，可选≤19 格从 0.0% 升到 0.1%——熟练玩家第一次能感到"手头紧"，虽然还是不会输。
6. **单局长度**：典型（noise）中位 **92 步**，第一次落进长期目标 **60–120 步**；乱放 23 步远低于目标；贪心 206 步高于目标。注意目标区间是按"随意打法"定的，所以"达标"只对 noise 这一档成立，而它恰好是最接近真人的那档机器人。
7. **性质判断（给决策用）**：平均余量几乎没变（贪心中位平均可选落点 174.8 → 141.6，可选≤19 格 0.3% → 2.5%），变的是**尾部**（一局最紧时刻中位 **19 → 2**）。这不是"整体变难"，而是"多了一个偶发但致命的形状"。要"整体变难"得动机制（见 KNOWN_GAPS 的机制级选项），要"回到不会死"只需动 Block 9 一个权重。
8. **代价说清楚**：面板没动、死法变了，意味着玩家的失败体验从"被空间逼死"变成"手里一张 3×3 放不下"。这是**可归因的技术惩罚**（留空位就不会死：`space` 与刻意留空位的打法结束率 0%），但也可能是**挫败感**——真人怎么看，模拟回答不了。

## 2. 方法与口径

| 项 | 值 |
| --- | --- |
| 命令 | 见 §8；每臂 600 局（3 种子 × 200 局），`space` 每臂 150 局 |
| 上限 | 600 步；超过即右删失，不是"600 步通关" |
| 臂 | `soft75/uniform` = 现行池（14 类，四格件×2、其余×1，Block 9 权重 1）；`current/uniform` = v0.8.4 之前的十类等权池；`b9w04` / `no9` = 现行池把 Block 9 权重改 0.4 / 删掉 |
| 打法 | `random` 每步在全部合法落点等概率乱选；`greedy` 每步取立即消除线数最多的落点；`noise` 75% 贪心 + 25% 随机；`space` 一步前瞻启发式 |
| mobility | 手上**仍然存在的不同形状**的合法物理落点总数（同形候选不重复计权） |
| 极紧步 `tight` | 该步 mobility ≤ 8 |
| 12 步分桶 | 每 12 步一个进度桶，桶内统计"仍在场的对局" |
| 面板口径 | 见 [紧张度测量 §2](DIFFICULTY_TENSION.md)：mobility 会被小件放大，抗膨胀的是"三块全可放"与"一局最紧时刻" |

**三个必须记住的边界**：①模拟无道具，而真人卡住时有换批可救，所以真实结束率应**低于**下表；②分桶曲线只统计仍在场的对局，**幸存者偏差**；③机器人不是真人水平分层，Wilson 区间只表达该策略的抽样不确定性。

## 7. 待决（制作人口径）

1. **要不要"会消除也会死"**：现行池把贪心打到 92.5%，是"技术梯度"（留空位不死）也是"挫败"（3×3 放不下）。要留就留，要缓就把 Block 9 权重降到 0.4（一行改动，`SHAPE_WEIGHTS`）。
2. **单局长度**：noise 中位 92 步达标、乱放 23 步过短、贪心 206 步过长。三档没法用同一个旋钮同时修——降 Block 9 权重会把 noise 推回 158 步（超出目标区间上沿）。
3. **道具现在真的有用了**：92.5%～99.7% 的对局会卡住，而卡住发生在"同一手里大件留到最后"的一步（`gamesEndingOnFreshDeal` = 0%），**换批正好救这一手**。模拟不含道具，所以真人的真实结束率会低于本文全部数字——这一点值得单独实测（真人试玩，不是模拟）。
4. **下一步可做的测量**：给逐局记录加一个"死亡时手里剩什么"字段（`endHand`），就能直接统计"多少局死于 Block 9 / Rect 6"，而不是靠臂对照反推。目前 `tools/` 没记这个字段，本文的归因是用整池对照做的。

## 8. 与 Block Blast 的结构对照：为什么同一个 3×3 在那边不致命

**Block Blast 的规则事实**（第三方资料，非官方文档）：Hungry Studio 出品，iOS 于 2022-04-03 上线，2024–2025 成为全球头部休闲游戏；玩法是 **8×8 单平面（64 格）+ 每批三块 + 拖放 + 不可旋转 + 满行/满列消除 + 无计时**，三块都放不下即结束，可立刻重开；模式含经典无尽、Adventure、每日挑战（[blockblast.co FAQ](https://blockblast.co/ko/faq)、[namu.wiki](https://en.namu.wiki/w/Block%20Blast!)，国内媒体亦有"3 亿 MAU、月流水超千万、曾遭谷歌下架"与腾讯洽谈入股的报道：[网易 1](https://m.163.com/dy/article/KUB4I348052685Q5.html)、[网易 2](https://m.163.com/dy/article/KMPVCEM605568W0A.html)）。它的发牌是否看盘面**没有官方说法**；公开分析普遍称其"随机选取、不检查未来可行性"（[Playgama FAQ](https://playgama.com/blog/game-faqs/why-does-block-blast-sometimes-have-no-solution/)），属二手说法，不能当成已证事实。

**关键差异不是"有没有 3×3"，而是 3×3 相对于盘面有多大。** 同一个九格件：

| 盘面 | 3×3 占盘面 | 空盘上的 3×3 落位 | 一条线消除占盘面 |
| --- | ---: | ---: | ---: |
| Block Blast：8×8 单面 | **9 / 64 = 14.1%** | 36 个 | 8 / 64 = 12.5% |
| 本作：5×5 面（六面之一） | **9 / 25 = 36.0%** | 9 个 | 5 / 25 = 20.0% |

**几何上的脆弱性差约 2 倍以上。** `node tools/face-fragility.mjs`（均匀随机占用模型，2 万次/格）给出"面/板上已经没有任何空 3×3 窗口"的概率：

| 占用率 | 5×5 面（本作） | 8×8 板（Block Blast） |
| ---: | ---: | ---: |
| 8% | 10.3% | 0.0% |
| 16% | 38.0% | 0.9% |
| 24% | 71.6% | 16.1%（23%） |
| 31% | 90.7%（32%） | 50.3% |
| 40% | 97.8% | 80.3%（39%） |

读数：**本作的面在 16% 占用时就比 Block Blast 的板在 31% 占用时更放不下 3×3。** 贪心打法死亡时的平均占用是 25/98 格（26%，按面均摊约 4.2 格/面 ≈ 17%），对应的 5×5 概率约 38%——而这还是**均匀随机**占用下的下界：真实盘面被消除聚成条带，会一次挡住多个窗口，所以实际更脆。这就是"同一个形状，在那边是普通大件、在这边是接近开关"的全部原因：**我们把 5 宽的平面切成了六块 25 格，而大件是按整块面来要求连续空位的。**

**本作也有 Block Blast 没有的补偿**：①每条线清掉面盘的 20%（对方 12.5%）；②一次落子同时检查**六个面**，多面同爆是常态；③道具（换批/锤子/火箭/炸弹）——但模拟里没有道具。

**给决策的选项**（前两条已实测，后两条未测）：

| 选项 | 预期数值方向 | 状态 |
| --- | --- | --- |
| A. Block 9 权重降到 0.4 | 贪心 92.5% → 69.5%、中位 206 → 386；noise 99.7% → 95.3% | 已测（§6） |
| B. 删掉 Block 9（13 类） | 贪心 → 1.7%、noise → 15.8%，回到"会消除就不会死" | 已测（§6） |
| C. 保留 3×3，但给"卡住"一条保底（换批保底 / 卡住时必发可放形状 / 复活） | 结束率下降幅度取决于保底强度；**Block Blast 类产品的宽容正是靠"继续/复活"这类机制兑现的** | 未测，可在 `tools/` 加臂 |
| D. 结构性：把面做大（6×6 面 → 3×3 只占 25%）或允许跨面放置 | 几何脆弱性直接下降，但棋盘、渲染、相机、存档全部要重做 | 未测，成本最高 |

**判读边界**：§8 的几何表是均匀随机占用的一阶代理，不是任何游戏的模拟；Block Blast 的细节（发牌是否看盘面、是否有复活）来自第三方资料，未经官方确认，不能当作设计依据。

## 9. 复现

```bash

# 规则层与测量模型自检（25 组，含"测量池＝游戏权重表"防漂移断言）

# 主表：现行池 vs 十类池 × 三种打法 × 3 种子 × 200 局 = 3600 局（约 39 秒）
node tools/difficulty-abcd.mjs --arms=soft75/uniform,current/uniform --games=200 --seeds=1,2,3 --strategies=random,greedy,noise --out=tools/results/difficulty-pool14-curve.json

# 熟练打法（一步前瞻）：2 臂 × 3 种子 × 50 局 = 300 局（约 91 秒）
node tools/difficulty-abcd.mjs --arms=soft75/uniform,current/uniform --games=50 --seeds=1,2,3 --strategies=space --out=tools/results/difficulty-pool14-curve-space.json

# Block 9 归因：2 臂 × 3 打法 × 3 种子 × 200 局 = 3600 局（约 37 秒）
node tools/difficulty-abcd.mjs --arms=b9w04/uniform,no9/uniform --games=200 --seeds=1,2,3 --strategies=greedy,noise,random --out=tools/results/difficulty-block9-sweep.json
```

`b9w04` / `no9` 两个池 id 是 v0.8.15 为本文新增的**测量臂**（`tools/difficulty-model.mjs`），它们跟随 `SHAPE_WEIGHTS` 只改 Block 9 一个权重，并由 `tools/difficulty-tests.mjs` 断言成员数与权重，防止漂移成"测了另一个池"。**它们没有接进游戏**：游戏里 Block 9 仍是权重 1。
