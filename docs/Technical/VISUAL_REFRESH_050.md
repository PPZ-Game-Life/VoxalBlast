# v0.5.0 视觉升级验收

日期：2026-09-14。基线：制作人授权实施 05 文档顶部视觉裁决。

## 实现

- 六面圆角格槽 + 不透明深蓝外壳，当前面提亮，背面深度遮挡。
- 同一晶格被多个面共享时，所有对应格槽一起隐藏，避免格槽盖住彩色积木。
- 同源灯光、曝光和塑料材质；低性能档阴影贴图降至 1024，高档 2048。
- 消除线光束、星星、粒子及道具粒子沿面法线外移，适配实体外壳。
- 主页使用棋盘几何缩影，静态按需渲染，不新增常驻动画循环。
- 统一白色厚底 UI、矢量道具图标、中文设置、×2 起点亮的连击条；正式版隐藏版本。
- 主页旧 CSS 整段替换；`toy.css` 集中管理现行视觉。其余历史布局规则保留，未宣称完成整个旧样式表清理。

## 已完成验证

- `npm test`：216/216 规则检查通过。
- `npm run build`：通过；仍有主包大于 500 kB 的 Vite 提示，未引入新依赖。
- 1280×720 桌面实机：主页、对局棋盘和三张候选完整显示，真实鼠标拖拽成功落子并加 40 分。
- 390×844 竖屏实机：道具在上、候选在下，棋盘与 UI 无重叠；设置面板全部按钮可达。
- 844×390 横屏实机：主页双列，局内左棋盘、右候选与道具；修复窄候选卡片的拼块裁切和页面滚动条。
- 正式构建本地预览：版本号不显示，主页可进入对局，D 键成功翻面，检查到的控制台 error 列表为空。
- 从设置回到主页保留本局分数和格数，可继续游戏。

## 验证边界

本轮在桌面浏览器内调整视口验证布局，未使用物理手机测试触感、GPU 帧率或平台广告流程。消除反馈保留现有等级与时序；未做全等级粒子逐帧录像验收。游戏难度、阶位标定等既有策划问题不属于本次视觉改版。
