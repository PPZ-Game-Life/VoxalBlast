# 拖动与预消除反馈

2026-09-24，基于 v0.9.0，按用户要求调整。

- 合法预放置使用候选的渲染颜色；重叠、部分越界以及未附着到棋盘的拖动显示中性灰 `#9299A2`。越界预览保留实际位置，不再把整个形状强行夹回合法边界；松手仍按 `Board.canPlace` 判断，非法位置不落子、不扣除候选。
- 无效松手或主动取消后，方块用 420ms 回到原备选格。复用候选的渲染器拍下当时的三维姿态，生成只负责显示、不接收输入的短暂飞行画面；缩小并恢复颜色后移除。拖动和回弹期间隐藏原候选，避免出现两个副本。新拖动、暂停或候选重建会清理旧回弹。
- `Board.previewLines` 在独立占用表上计算六个面的完整行列，不改实时棋盘、分数或回合。共享棱角导致的跨面消除同样参与预测。`boardView` 仅临时替换预计消除格的材质，挪走、取消、松手、重开及读档都恢复实际棋盘材质。
- 预放置、在手方块与回弹均沿用共享圆角几何和漆面材质；去掉旧版高透明度线框边线。

例：把红色单格放到一行唯一的空格上，整行临时显示红色；移到别处，原有蓝、绿、紫等颜色立即恢复；松手确认才真正消除。

验证：新增 38 项规则检查，覆盖六个面、重叠、越界、共享棱角、数据不变及预测与实际结果一致。完整单元测试 827 项通过，交互 52 项、扩展拖拽 54 项及开发构建 UI 67 项通过，无跳过。新增浏览器检查读取实际材质、回弹时间进度和截图像素，覆盖恢复原色、取消、快速重抓和真实消除；最后一次定向 D/H/I 检查 21 项通过。美术例图在 `artifacts/placement-feedback/`，日志在 `artifacts/placement-*.log`（不入库）。
