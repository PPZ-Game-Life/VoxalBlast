## 0. 给 Jeffy 的执行摘要

**目标：明亮田园中的精制积木。空格是温润浅木，彩块是干净的柔光彩漆；六面体有体积、有可信承托，不像亮面键帽贴在插画上。**

本次有两个独立问题：

1. **塑料感**：强清漆、多组环境反射、重复宽倒角与微凸法线叠加。
2. **拼贴感**：实时六面体与二维底座的透视、受光和接触关系没有充分统一。

执行顺序：

| 阶段 | 唯一主要问题 | 通过后才能做什么 |
| --- | --- | --- |
| G0 冻结 | 基线与条件是否可复现 | 开始对照 |
| G1 接触诊断 | 三维承托是否明显改善落地感 | 决定底座路线；不要凭理论默认全 3D 更好 |
| G2 光泽 | 木和彩漆是否摆脱亮膜感 | 进入形体实验 |
| G3 形体 | 是否仍像键帽或软垫 | 锁定单块造型 |
| G4 材料与承托整合 | 新方向在整盘、候选和底座上是否一致；本阶段内依次确定资源需求 → Luna 交付 → Jeffy 接入 → 最终整合验收 | 进入 G5；不得先验收占位效果、通过后才接最终资产 |
| G5 回归与验收 | 多姿态、多视口与低性能档是否成立 | 发布与更新实现文档 |

**一个阶段可以包含多轮。每轮只验证一个假设，不要一次改灯光、材质、倒角、相机、色板和背景。** G1–G4 各门禁由 Luna 给“通过 / 附条件通过 / 退回”；材质方向或交互取舍有争议时交制作人裁决。阶段未通过，不把其试验参数扩散到下一阶段。

## 2. 源码事实：不要误诊

| 项目 | 当前核对事实 | 对本方案的含义 |
| --- | --- | --- |
| 场景结构 | 背景是 DOM 图片；底座是独立 `pedestal.webp`，不是和背景合成的同一文件；六面体为实时 3D | 问题是缺少共同空间信息，不是图片文件数量 |
| SSAO | `gameScene.js` 通过 NormalPass 的法线与深度计算；底座透明接影面在 layer 1，被排除出该预通道 | SSAO 不知道图片石台的形状；调强它不能自动生成台面接触 AO |
| 底座阴影 | `boardShadows.js` 使用径向渐变贴片 + ShadowMaterial 平面；透明度分别 0.24 / 0.18 | 已有模拟接触与真实投影，并非完全没阴影；但承托不是图片台面的真实几何 |
| 质量档 | `SHADOW_STYLE.lowPowerSSAO=false` | 低档必须在没有 SSAO 时成立；不能假定用户当前一定处于低档 |
| 彩块 | roughness 0.22、clearcoat 0.85、coat roughness 0.12、metalness 0 | 已是非金属，但仍偏光滑清漆；只改基础 roughness 不够 |
| 木块 | roughness 0.48、clearcoat 0.45、coat roughness 0.18 | 木材也有明显涂层响应 |
| 形体 | size 0.95、radius 0.13、segments 3；木和彩块 crown 均 0.012 | 大倒角与光学鼓面可能重复强化键帽感 |
| 体积响应 | scatter / coreAbsorption / internalReflection / environmentTransmission 均为 0 | 不再把现状归因于“果冻散射没关”，也不要恢复它们 |
| 环境 | softbox 8、竖卡 2.6、小光点 16、环境轮廓 4，另有实际方向光 | 可隔离检查多重反射，不能把所有亮边都说成贴图画死 |
| 候选 | 已共用几何和材质工厂；独立近正面正交相机，无棋盘完整后处理链 | 不重建一套模型；需要校准输出，而非宣称原来是 CSS 假 3D |

## 5. G1：底座接触诊断，先证明收益

### G1a｜分离三种阴影的贡献

材质、灯光与几何保持不变，在同一姿态分别输出：

- A：现状全部开启。
- B：仅关闭 SSAO，其余保持。
- C：仅关闭底座径向接触贴片，其余保持。
- D：仅关闭底座实时投影，其余保持。

A 对 B 看格缝，A 对 C/D 看底边和台面。分别记录差异区域；不把“整张图有像素变化”当成接触关系已经正确。已有 `tuneShadows` 可调两种底座阴影，SSAO 单独开关若尚未提供由 Jeffy 增加开发诊断，不虚构现有接口。

### G1b｜二维底座 vs 简单三维承托样板

- 临时隐藏 DOM 底座，保留原田园背景。
- 用**简单圆形低矮 3D 台面**替代，不做花叶、石缝或复杂模型；色调接近现有浅奶油石材。此样板不是终版资产。
- 按静止棋盘底部标定台面高度，按现有底座屏幕轮廓标定承托宽度；不移动棋盘或修改相机凑图。
- 可见台面进入真实几何/法线/深度链，接收主光投影；现有 ShadowMaterial 接影平面不是实体台面，不能仅把它改到 layer 0 就宣称“真实底座 AO 完成”。
- 防止新台面投影与旧接影层重复：三维样板关闭旧投影接收面；接触贴片作为独立开关保留，先比较其关闭状态，再判断低档是否需要兜底。
- 对照拆成“二维现状 vs 三维台面（均关 SSAO）”及“三维台面 SSAO 开/关”。避免把换模型、加 AO 和换材质的效果混成一个结论。

**特别门禁：翻转穿插。** 当前棋盘绕中心翻面，45° 时角点可能低于静止底面；真实台面会暴露旧二维底座掩盖的穿插。必须检查 X/Y 翻面、Z 轴转动及开场缩放。不得为绕过问题改变逻辑枢轴、禁用底部可玩块深度、强行把整盘永远画在最前，或擅自添加棋盘抬升动画。若穿插/遮挡不可接受，G1 不通过，带证据回 Luna 裁决承托间距或保留二维承托路线；不把静止截图通过当作完整通过。

### G1 出口：必须明确选一条

- **路线 A（优先验证）：二维远景 + 简单三维承托主体。** 落地感明显改善，翻转无遮挡/明显穿插，性能可接受后采用。侧壁与花叶可保留分层二维装饰，前提是多视口透视接缝可控。
- **路线 B（可接受回退）：保留二维底座，重做接触/投影匹配。** 若三维收益小、转动穿插或混合接缝成本不合理，继续使用图片；接触影需更贴近底部轮廓，近处较实、外沿渐软，不能只放大一团圆形污影。记录其为视觉近似，不宣称真实台面 SSAO。
- 若二者都不满足门禁，回报最大差异，不进入资源重制或整景 3D 化。

## 6. G2：收敛光泽，保留鲜明颜色

目标不是“所有高光消失”，而是**大部分面积读到本色，少量宽柔反光解释涂层**。

建议子轮顺序：

1. 固定材质，只关闭/降低环境小光点，确认它对刺亮点的贡献；下一轮单独降低竖反射卡。保留主软箱，不同轮同时重做所有灯光。
2. 固定确认后的光场，先做彩块清漆层对照，再调基础粗糙度。
3. 单独调木块，使木材明显比彩漆更安静。

| 参数 | 当前木 / 彩 | 本次探索范围（非终值） |
| --- | --- | --- |
| roughness | 0.48 / 0.22 | 木 0.60–0.75；彩 0.35–0.50 |
| clearcoat | 0.45 / 0.85 | 木 0–0.15；彩 0.10–0.30 |
| clearcoatRoughness | 0.18 / 0.12 | 清漆非零时试 0.25–0.40；清漆为零时不纠结此值 |
| metalness | 0 / 0 | 保持 0 |
| Gem 四项体积响应 | 均 0 | 保持关闭 |

注意：roughness 还会乘贴图，不能把参数当最终观感。envMap 必须保持显式绑定；环境 PMREM、表面法线缓存需正确刷新，避免“改了常量但旧缓存还在”。不靠调暗 baseColor 对抗白反光。全局曝光先固定，光泽通过后才讨论必要的局部调整。

**门禁：**手机实际像素下不再像覆亮膜；彩块不变灰粉；木格不油亮；旋转不会突然爆出整面白光。单块样板、候选与彩盘共同判断。G2 不改倒角、crown、色板或相机。

## 7. G3：恢复“面平边柔”，去键帽感

- 第一子轮固定几何，只比较 crown 现状 0.012 与更低值（0–0.006），木/彩分开验证。零值可用于诊断，不因旧文档“不能为零”而禁止比较。
- 第二子轮固定已确认材质与法线，倒角 radius 从 0.13 试向 0.09–0.11；size 0.95、pitch 1、segments 3 暂时不动。
- 不增加整块厚度、不抬高彩块、不改命中体积或共享棱角规则。
- 先看 390px 全图与约 240px 缩略图，再放大检查；木块应像实心小木块，不像软垫、键帽或饼干；彩块保留清晰平面。
- 检查棱角、缝底、预览、拖拽、消除前后及低分辨率锯齿。不要用增加细分或加深 AO 掩盖轮廓比例问题。

## 8. G4：材料差异、最终承托与美术资源

### 8.1 材料层级

- 木格：浅奶油木色、少量低对比纤维、受控粗糙变化；不做高频年轮、大黑节疤、随机污斑。
- 彩块：不透明柔光彩漆，色面干净，不必露出明显木纹；材质差异应由颜色/反射/微表面共同提供。
- 接缝：窄暖暗部，不追求黑框。保留空格与已占用的辨识度，特别检查黄块与浅木。
- 候选、拖拽、棋盘使用同一材料与几何入口；分别校准实际像素、接触阴影和输出，不因同源就直接宣告一致。
- 本方案不调整候选槽尺寸或预览相机。如候选厚度仍是最大问题，单独回报，不挤占取消区。
