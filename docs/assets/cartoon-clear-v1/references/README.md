## 使用边界

- 图片用于视觉语言与构图对齐，不作为程序状态、网格拓扑或逐粒子数的真值。
- 多消图四格不是一条动画时间轴。第四格的侧视角只用于解释跨面，不要求消除时自动转面。
- 多消图用蓝/青区分面线；正式程序中共享格只有一个真实颜色身份，不得为了像图而让共享实体两面出现不一致占用。
- 前三格近正视且格子比例为概念表达，不能照图改现行相机、实体尺寸、间隙、描边或拾取模型。
- 具体时序、粒子预算、去重、恢复空格、音效避让及验收按 [Jeffy 交接单](../../../Technical/CARTOON_CLEAR_VFX_HANDOFF.md)。
- 原图不部署进 `public/`，不作为运行时背景、粒子图集或UI整图。
